# CLAUDE.md（20-eos-engineering · EOS 主线工程）

本目录是 AOS 项目集里的**主线工程**——把「元流水线 → EOS 流水线 → EOS 本体」这条链完整工程化。它是项目集共同目标（为业务建立基于 AI 的流水线）最系统的一次展开。

## 边界与执行路径

- **处理本工程**：工作目录 = 本目录或仓库根，读本文件 + 仓库根 [`CLAUDE.md`](../CLAUDE.md)，记忆读写仓库根 `.claude/memory/`。
- **处理其他项目**：工作目录 = 对应项目目录，读对应项目的 `CLAUDE.md`——**不擅自改动其内容**，除非明确要求。
- **主题上可互引、操作上自包含**：本工程的方法与结论可被各项目引用，反之亦然；改动落在谁家由谁做。

## 目录

| 目录 | 内容 |

## 提交边界

仓库是 AOS 单一 git 仓库。本工程改动与各独立项目改动**分别 commit**，commit message 注明归属；处理本工程时不把其他项目的改动混入，反之亦然。
