## 五层结构

```
第1层：原始需求 (OR)         → 01
    ↓ N:1 分配
第2层：相关方需求 (SR)       → 02（架构定义）+ 03（详细定义）
    ├─ 功能部分 ↓
    │   第3层：业务流程 (BP)  → 04
    │       ↓
    │   第4层：系统需求 (SysReq) → 05（架构定义）+ 06（详细定义）
    │       ↓
    │   第5层：产品架构 (PA)  → 07
    │
    └─ 非功能部分 ↓
        第4层：SysReq-NFR    → 05（非功能部分）
            ↓
        第5层：PA            → 07（非功能约束）

追溯矩阵                    → 08
验证报告                    → 09
```
