```mermaid

    C --> D{"快照版本一致"}
    D -->|否| D1["重采快照 · 或提示页面已变化"] --> B
```

## 四、绑定结果状态机

```mermaid
stateDiagram-v2
    [*] --> 求值
    求值 --> ok: 命中且唯一
    求值 --> unbound: 依据在快照中不存在
    求值 --> ambiguous: 命中但多候选
    求值 --> out_of_range: vis_token 不匹配
    求值 --> denied: 权限交集不通过
    求值 --> stale: 数据版本与快照不一致
    求值 --> type_mismatch: 构造子类型与槽位不符

    ok --> 执行
    ambiguous --> 澄清卡: 出卡请人类指定
    澄清卡 --> 执行: 人类点选后重新绑定
    stale --> 重绑定: 拉最新行集合重算序号
    重绑定 --> 求值
    unbound --> 回灌模型: 附可选值清单
    out_of_range --> 回灌模型: 附可见范围
    type_mismatch --> 回灌模型: 附槽位类型声明
    denied --> 回灌模型: 附拒绝原因
    回灌模型 --> 求值: 模型改口
    执行 --> [*]
```

**报错必须区分 `unbound` 与 `ambiguous`**：前者要模型重新表达，后者只需人类点一下——混为一谈会让模型白重试或让人白等。

## 五、异常与降级

```mermaid
flowchart TD
    A["执行或回灌任一环节异常"] --> B{"异常类型"}

    B -->|模型超时 / 不可用| C["提示 智能助手暂不可用 · 本地正则通道仍可用"]
    C --> C1["纯操作意图照常执行 · 打开第 N 行 / 改排序"]

    B -->|绑定失败| D["回到协议段② · 附诊断让模型改口"]
    D --> D1{"重试 ≤ 2 次仍失败"}
    D1 -->|是| D2["反问人类 · 请说明要操作哪一行"]

    B -->|取件失败| E["ToolResult 置 failed · recoverable=true · 附替代候选"]
    E --> E1["模型把失败翻译成对话 · 这份有密码 要不要改分析另一份"]

    B -->|权限不足| F["不执行 · 说明原因 不暴露无权数据是否存在"]

    B -->|数据已变更 stale| G["按主键拉最新数据 · 重算可见序号 再绑定"]
    G --> G1{"记录已删除"}
    G1 -->|是| G2["告知该行已被删除 · 刷新列表"]
    G1 -->|否| H["继续执行"]

    B -->|轮次或预算熔断| I["停止取数 · 用已有素材作答 · 声明信息不完整"]

    B -->|等待超 60 秒| J["转异步作业 · 对话区显示进度 · 允许离开页面"]
```

## 七、实现分期

```mermaid
flowchart LR
    P1["第一期 · 快照 + 表达式 + 绑定 · 受控句式与右键菜单 暂不接模型"] --> P2["第二期 · 接入模型做自由表达 · 读路径 统计与取件 · 三道熔断"]
    P2 --> P3["第三期 · 写路径 提案确认 · 动作候选闭环 · 审计落库"]
    P3 --> P4["第四期 · 开放问答 · 跨场景分析 · 主动巡检"]

    P1 -.- P1N["验收：指代锚定稳定 · vis_token 生效 · 快照服务端持有"]
    P2 -.- P2N["验收：统计范围可回指 · 长文档不爆 token"]
    P3 -.- P3N["验收：AI 无法绕过 · 表单校验与节点权限"]
```

**第一期不接模型也能做**——用右键菜单与受控句式先把"快照—表达式—绑定"骨架验证扎实。瓶颈从来不是模型的理解力，而是指代能否稳定锚定到数据。本地正则通道自始至终保留，只承担高频纯操作，不承担理解职责。
