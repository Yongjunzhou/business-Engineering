# 元流水线设计规范

**目录用途**：存放元流水线的设计描述与术语对照。各层通用方法条目格式见[通用设计规范](../../00-generalspec/01-generalspec-sysdev.md) §五（系统设计过程）。

## 本目录文档

### 01-pl4pl-spec-sysdev.md
**元流水线系统设计规范**（精简版）

**结构与定位**：以通用设计方法论为基础，只保留元流水线特有的产品语境与导航，不重复展开各层指引与四模式操作（完整内容见 [EOS 流水线系统设计规范](../../20-pl4eos/00-pl4eos-spec/01-pl4eos-spec-sysdev.md)）：

- **§一 前言**：文档定位、受众与阅读前提
- **§二 产品语境**：元流水线的身份、三层构造链与 A1→A2→A3 产品链
- **§三 工程设计导航**：通用规范 → 元流水线规范 → EOS 流水线规范 → EOS 规范的阅读路径
- **§四 Skill 文档规范**：元流水线 Skill 文档的要素与章节框架（规范性定义引 EOS 规范 §十五）

**用途**：说明元流水线是什么、它的规范在哪里，以及设计元流水线产出物时该读哪份文档。
