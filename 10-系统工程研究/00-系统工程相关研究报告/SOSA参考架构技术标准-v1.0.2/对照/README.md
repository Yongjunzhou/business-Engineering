## 八、中文目录（接在英文印刷式目录之后）

前置册里，英文的印刷式**目录／图清单／表清单**照录不译（版面构件，包在 `<!-- 未译 … -->` 里）；其后接一份 **`### 中文目录`**，是**译者所加**，包在 `<!-- 装置 … -->` 里：

- **中文名不另译**：直接取正文各册题、节题、图题、表题已定的并置名，故与正文用词天然一致；
- **页码**取该题最近的原书页锚（`<!-- 原书 p.N -->` 或 `> 原书 p.N` 页范围行），可与上面的英文清单对查；
- 结构：**一条顺下来，不分级、不另起段、也不缩进**——层级只由编号本身体现；共 168 条章节题，其后接 `**图清单**`（50）与 `**表清单**`（47）。

生成脚本 `.work-sosa/gen_toc.py`（改分册后重跑，再依次 `build00.py` → `build_full.py` → `copy_to_root.py` → `fix_copies2.py`）。机械关把 `<!-- 装置 -->` 与 `<!-- 未译 -->` 同等处理，不参与段配对。**`build_full.py` 现含 APPENDIX 段**：它把卷末附记 `附记-架构标准符合性核查.md` 拼在十六册之后并自动进目录，重生成合订本时不会漏。
