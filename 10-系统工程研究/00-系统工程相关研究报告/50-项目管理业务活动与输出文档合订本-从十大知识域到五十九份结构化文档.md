## 一、总则

### 1.1 三条判据与四条硬要求

| 判据／要求 | 内容 | 不过关的样子 |
|---|---|---|
| 活动判据一 | 有独立目的，这一步产出的东西别处产不出 | 两条活动合并后不损失信息 |
| 活动判据二 | 有唯一主责，落到岗位或人名 | 主责写"项目组" |
| 活动判据三 | 有第三方可判的完成判据 | 做完没做完由执行者自己说 |
| 硬要求一·条目可编号 | 每个"一条一条"的东西有唯一编号，全项目不复用 | 风险写成一段散文 |
| 硬要求二·责任落到人 | 每条有且只有一个责任人，填人名或岗位 | 责任栏填"相关方" |
| 硬要求三·判据可判 | 每条写清怎样算完成或通过，写成可观察事件 | 完成判据写"满足要求" |
| 硬要求四·可对账 | 每条挂上游引用编号，能从结论倒推回源头 | 验收报告不挂验收准则编号 |

### 1.2 文档包的四类件

| 件 | 作用 | 缺了会怎样 |
|---|---|---|
| 主件 | 写活动的判断与结论，章节骨架固定 | 只剩条目，看不出结论 |
| 登记表 | 逐条可跟踪的条目集合，四栏齐备：编号、责任、判据、状态 | 内容成散文，事后查不到条目 |
| 记录 | 事件留痕：评审、会议、检查、裁决 | 说不清谁在何时认过 |
| 基线件 | 谁在什么时候批了哪一版 | 版本失效，引用指错 |

主件与登记表是底线，四件其余两件按活动性质取舍。章节骨架是下限，项目可加不可删。

### 1.3 标识、状态与编号

| 要素 | 规定 |
|---|---|
| 文档标识七要素 | 编号、名称、版本、状态、责任人、生效日期、关联条目范围；缺一项即视为草稿 |
| 状态机 | 草稿 → 送审 → 批准 → 基线 → 变更中 → 关闭，只能进不能跳 |
| 基线态 | 不许就地改；改则另开新版并走 A40 变更流程 |
| 活动编号 | `A` + 两位序号，按生命周期排号但一经分配不再变动 |
| 文档编号 | `D` + 与活动同号 |
| 条目编号 | 前缀 + 三位序号，全项目唯一；作废保留原号标`作废`，不许回收 |

### 1.4 责任角色

| 角色 | 管什么 |
|---|---|
| 业务发起人 Sponsor | 立项理由、资源承诺、项目终止 |
| 治理委员会 Steering Committee | 基线批准、重大变更、阶段门 |
| 项目经理 PM | 计划集成、报告、变更受理、整体协调 |
| 领域负责人 | 范围、进度、成本、质量各条线的专业判断 |
| 职能经理 | 人员调配、能力建设、绩效 |
| 质量负责人 | 检验点、审计、不符合项 |
| 采购负责人 | 采购包、供方、合同 |
| 配置管理员 | 文档登记、版本、归档 |
| 供方 Supplier | 合同范围内的交付 |
| 客户／接收方 | 需求来源、验收、移交接收 |

## 七、空格与偏离

### 7.1 矩阵里的十八个空格

| 空段 | 空的是哪几格 | 为什么空 |
|---|---|---|
| 启动段 8 格 | 范围、进度、成本、质量、资源、沟通、风险、采购 | 启动期只办三件事：这件事要不要做、谁批准、牵涉谁。八条管理线在规划段才各自立起来。相关方不空，A05 就在启动段 |
| 执行段 3 格 | 范围、进度、成本 | 执行期的交付记在 A28 与 A41，天数与花销由 A38、A39 记账；这三条线在执行期产新件，就是该进变更了 |
| 收尾段 7 格 | 进度、成本、质量、资源、沟通、风险、相关方 | 收尾只办验收、移交、结算、复盘、归档、后评价六件事。七条线的收口各有归属：成本归 A51，质量判定归 A49，人员与权限、沟通材料、残余风险归 A53，满意度归 A48 |

### 7.2 与通用四十九过程清单的七处偏离

| 偏离 | 本体系的做法 | 理由 |
|---|---|---|
| 范围、进度、成本三份管理子计划 | 并入 D26 的对应章节，不单立文档 | 三份子计划各自只有半页，单立等于制造空壳 |
| 定性风险分析与定量风险分析 | 合成 A21 一条，定量作其中可选项 | 定量只在数据齐全的大项目上立得住，其余场合是伪精确 |

## 十、使用方式

| 步 | 做什么 | 判据 |
|---|---|---|
| 一·建册 | 以 §二 全表为母表，复制成项目自己的活动台账 | 删或合并的行都写了理由 |
| 二·挂码 | 每条活动开工前先立文档编号与条目前缀 | 没有编号的活动不许开工 |
| 三·对账 | 每个阶段门前按 §五 十一条核一遍，再按 §三 矩阵看本方需要的格子有没有对应活动与文档 | 核对结果作为门禁证据 |

三条底线：编号即身份，改号等于换了个东西；条目即证据，没有编号的结论不成立；空格即待判，理由说不通的空格就是活动没列全。
