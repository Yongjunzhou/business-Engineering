# 「承重测试」一名停用（2026-11-06 用户令）

**用户原话**：「承重测试，这个说法不要再用了」。

## 一 口径

- **停用的是名字，不是那条问法**。“把这一条内容拿掉，这个实体还达不达成目的”这句话照旧讲、照旧用，但**不给它起名**，直说“那句问法”。
- **它的位置**：**检查办法，不是判据**。判据是一支填句三槽（为谁判／作哪种判／删了哪句垮），见第10章 `10.2.3`。
- **理由**（沿用第10章三条）：把结果当构成、把贡献当必要、把条当类。
- **为什么停名**：一给了名字，它就会被当成一张可以贴的标签，读者拿它当判据用；而它连单条之外都管不到。
