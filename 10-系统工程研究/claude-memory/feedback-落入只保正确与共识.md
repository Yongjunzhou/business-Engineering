# 落库只保"正确＋共识"的内容

**用户原话（2026-11-04）**：「不是所有的内容都不得损失，而是正确的和达成共识的内容不得损失」。

**指示**：把讨论落入报告时，先逐条判性质，再决定存留：

1. **标准逐字/条款**——存，标条款；
2. **已达成共识的结论**（用户点头，或双方确认）——存；
3. **本报告读法/操作化**——存，但**必须标〔读法〕**，不得写成标准规定；
4. **被推翻/已更正的说法**——不存为结论；只可进"推翻与更正台账"作历史；
5. **未获用户裁定的提议**（含我自己的推论、待点头事项）——不当结论存；必要时进"未决/挂账"，不混进正文。

**操作**：落库前对每条问一句"这条是标准、共识、读法，还是待裁？"；答"待裁"的，不进正文。

**边界**：不是"所有讨论内容都不得损失"——错的与未裁的**可以损失**，而且应当损失；不得损失的是正确且达成共识的那部分。
