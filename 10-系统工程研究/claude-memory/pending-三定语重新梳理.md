## 二、三条纪律（本轮用血换的）

1. **不搬报告结论，也不搬报告的操作化**（"三把尺""一把尺三形态"只能当读法）。
2. **判据必须可操作**：祈使句不算；要能填句、能复核、两人各做一遍能对上。
3. **结论式论证一经指出就认并重做**：拆成依据／推理／反证／边界，或承认该句错并改。

## 三、六步骨架（第一轮可直接拿去定框架）

```
0 立参照系：问题/机会 → 需求 → 架构目标（42020 §8.4.4 f)）
   → 质量模型（g)）→ 关键成功准则（h)）→ 权重（i)）→ 评估准则（j)）
1 关键：需求对着"哪条准则"——事前判该不该进链；事后追"追到哪一条"
2 基本：内容对着"架构是什么"——概念看成套、属性看四量、原则看管控
3 相关：七种形态对着"这一处的那一问"——范围/宿主/细节/复检
4 依赖（关键⊃基本⊃相关）与工作顺序（两遍迭代；42020 §8.4 明说活动可任意顺序）
5 三张表＋留痕（判定·理由·映射；§6.2、§6.10.1、§8.4.6 注 3）
```

## 四、必须钉死的四处（本轮反复踩）

1. **三个词的参照物不同**：关键→**关键成功准则**；基本→**定义句（42010 §3.2）＋§5.2.2 五类**；相关→**这一位要答的那一问**。参照物不同 ⇒ 不可互相渗透。
2. **两个 fundamental**：42010 §3.2 修饰**内容**（准入）；42020 §8.4.4 注 3 的 *fundamental objectives* ＝ ends objectives ＝**关键成功准则**（目标侧）。
3. **覆盖 ≠ 不关键**：关键但已被现有内容答了的，**仍要进关键追溯表**。
4. **关键特征不是前置筛子**：42020 §8.4.6 里 d) 在 b)（构思概念与属性）**之后**，是概念雏形出来后认出来的。
