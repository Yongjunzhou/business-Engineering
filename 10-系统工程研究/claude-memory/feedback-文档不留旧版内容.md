# 文档里不留旧版内容（2026-11-27 用户令）

用户原话（01 号术语判读轮）：「文档中不要有相关旧版的内容」。

## 规则

1. 两件交付文档（数据本体与规范）里，旧版内容一处不留：术语表不设「改名前的旧称」列，正文不写「原称……」「原写作……」「已改……」，字段名、节题、定义只写现行的。
2. 版本记录（册附录 B、过程记录改动痕）写改了什么、为何改，一句带节号即可，不复述旧名与旧定义。
3. 旧名与新名的对照落 00 号台账一行；术语确认的账照元规范 3.1 也落那里。台账是登记件，不是交付文档。
4. 工作件（开工单、判读单）要抄现文才判得动，抄下的旧文留在工作件里作凭据，不进两件交付文档。

## 来历

01 号术语判读单原拟照元规范表3-1 给「改名前的旧称」一列，并打算把「研制方使命改作使命」一句写进册附录 B；用户当场否掉。已撤那一列，改在判读单里写一句「术语表只写现行的名，旧名与新名的对照不进册与数据，落 00 号台账一行」。

## 与既有规则的关系

规程 5.6 忌表的「旧版残留」管的是正文；本条把「术语表的旧称列」「版本记录复述旧名」也划进禁区，并给旧名一个落点：台账。
