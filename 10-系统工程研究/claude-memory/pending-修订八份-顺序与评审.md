## 二、次序（四段）

一是元规范，再元规程，裁完冻结成基线。二是 01→02→03 三册同轮交付。三是 01→02→03 三份数据同轮，01 先、02 次、03 末。四是收口：三条读数复算、交叉指针与号段、判例库补到三十三条、台账销账、分段提交。

做同轮的理由：三册这一轮要改的多是同源项（术语 3.1 与体例五条对齐、括号与量词、自指、符号单位、段长、元规范附录 A 指针、各册自己的待补），分三轮等于同一把尺量三遍、评审过三次。次序按编号链的理由：问题号→关切号→需求号，上游先改，下游的挂源重对一次就够。

## 三、工程师阅读：每份规范只留一处

位置：结构定稿、取值未填那一刻。册＝字段表与验收准则写完；数据＝第三阶段表头方案与转换规则交完。

给什么：只给三页（字段表、转换表、验收准则）加一句形态声明；三册同轮一次给九页，不按册分三次。理由：这时错的四样（形态、字段名、取值来源、号段）最贵也最好改；放到末道他只能提意见，改不动。

其余阶段靠四道机械关，读数与自核一律写进同号过程记录件：

| 关 | 判法 | 不过怎么办 |
|---|---|---|
| 列名与标题读数 | 两只脚本硬违规 0 | 改到 0 才进下一阶段 |
| 示例值三处对账 | 正文处数＝登记行数＝来路表 | 退回重标 |
| 号段与挂源核 | 每个号指得回上游那一条，拆号在表末续 | 断一处即退回 |
| 门自核 | 本册 5.1 逐条判到每条记录 | 改到过，改不动的进未完项 |

末道另加一次代理盲读（只给题面、不给背景），那不是工程师，不必慢。

代价照记：阶段五至七的内容与表达毛病只有末道一两轮机会，可能返工；补偿是四道机械关与他读的三页挡住结构错。
