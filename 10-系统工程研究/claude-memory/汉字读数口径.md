# 汉字读数口径（2026-11-13 立）

## 口径

量某件报告的「汉字数」，一律用：

```python
import io, re
s = io.open(路径, encoding='utf-8').read()
len(re.findall(u'[\u4e00-\u9fff]', s))
```

## 为什么立这条

36 号对齐轮（2026-11-13）发现：**PowerShell 的 `Get-Content -Raw` 在中文 Windows 上按 ANSI/GBK 解码无 BOM 的 UTF-8 文件**，同一份文件量出 22,947 汉字，而 UTF-8 口径实际只有 14,959（差 7,988，约 53%）。同时 `Get-Content` 的行计数也不可靠（同一文件 479 行 vs 实际 597 行）。

故：
- **凡写进记忆的汉字读数**，必须是 Python/UTF-8 口径；用 PowerShell 量的数不得直接与前序记录比对。
- 历史进度件（如 `progress-对齐35-46.md` 记 35 号 37,401→41,710）若当时用 PowerShell 量，其看「增减方向」仍可用，**绝对值不可与本口径混比**；需要时按上式复算一次。
