# 挂账：附录外移（自查＋练习）· 可压件占比批

## 〇 一句话

各章章末的**自查（附录 C）**与**练习（附录 D）**移到书末统一附录，把章末可压件占比一次压回线内。**用户 2026-10-28 裁「单独开一批，不并进冗余步」**，本件是这一批的开工单，**尚未开工**。

## 一 为什么单开、且不能在冗余步里做

- **冗余步只删正文，越删占比越高**：ch05 这轮只删正文 222 汉字、附录 A~E 一字未动，可压件占比反而由 **24.0%→24.6%**（分母缩小）。再清一两章正文，ch05 必越 25 线。**靠删正文解决占比，方向是错的。**
- **口径早就给出答案**：`00-风格参考.md` §6.1 的处置顺序写的是「改口径 → **外移自查练习** → 压反转」，并实测"再把自查＋练习外移附录 E，全书可压件尾部落在 7.3%~16.1%，无一章超线"。
- **属体例件决策**：动的是每章附录结构（章末 A~E 变 A~C），必须用户点头。用户已点头（2026-10-28）。

## 三 做法草案（五步，一步一停）

1. **出清单**：19 章各自 C／D 的条数、汉字、节内结构（有无引导句），落一张表；同时核每章 C／D 是否被正文互引（"见附录 C 第 N 条"这类）。
2. **定落点与编号**：两种方案二选一——① 书末新增「附录：自查与练习」一条，按章分节（19 节）；② 自查、练习各成一条书末附录。**推荐 ①**：读者按章查，一次翻到位；且章数与正文对齐，便于目录。
3. **改体例件**：`00-全书框架.md` §一 结构与附录行、目录须同批改（章末附录 A~E → A~C）；每章末尾保留"自查与练习见书末附录·第N章"**一行指针**（不写邀请式说明，只写去处）。
4. **施工**：19 章机械搬迁（内容一字不改）；搬完每章复算可压件占比，确认落到 7.3%~16.1% 区间。
5. **复算与留痕**：`00-风格参考-量尺.py` 三口径全跑；§3.3／§3.3之二 两张表与 §6.1 红线表的实测列一并在同一批换新（口径 C 变成现行口径后，"22%"这条线的分母含义要写清）。

## 五 风险三条

1. **读者查件路径变长**：从"翻到本章末"变成"翻到书末再找章"。缓解＝每章末留一行指针，书末按章分节、节题带章号。
2. **自查/练习与本章正文的呼应会断**：现文里"自查第 3 条"式的隐含呼应（读者刚读完就在章末撞见）会变弱。缓解＝书末每章节首不加重述，直接接条目；不做"回到第N节"的交叉引用（那会把指针塞满）。
3. **一次动 19 章的体例，量尺会同时变动**：必须**先改脚本口径、再改文本**，否则复算无基准（第一病"改件名要四把尺全跑"那类的坑）。

## 六 待裁（开工前须您定的三件）

1. 落点与编号：书末一条按章分节（推荐）／自查与练习各一条。
2. 章末是否留指针行（推荐留一行，只写去处）。
3. 这一批的**验收线**：以"口径 C 全书无一章超 22%"为线，还是以"每章落进 7%~16%"为线（推荐后者，前者太松）。

## 七 开工话术

用户发「**开工附录外移**」即启动；启动第一件事出**第一步的清单**（19 章 C／D 条数与汉字＋正文互引核查），**不许先动文本**。

## 八 与冗余步的关系

- 本批**不占**第二病（段落冗余）的工位；两批互不改对方的文本（冗余步只动正文散文段，本批只动章末附录与目录/框架）。
- 本批做完之后，第二病剩余各章的可压件读数应按口径 C 重跑一次，作为新的基线写进 `00-冗余优化台账.md` §三。
