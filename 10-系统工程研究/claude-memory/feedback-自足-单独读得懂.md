# 自足：能单独拿出来的内容，单独读得懂（2026-10-26 用户定；**已升为手册第一铁律**）

> **本件是指针件**：**规则正文**分两处——**手册导语「★★★ 第一铁律·自足」**（为什么排第一／管什么不管什么／取舍次序／怎么执行）＋ **§2.13 判据全文**（四条判法与施工习惯）；改版留痕在手册 **§0.4之三 十五**；记忆侧只记来历与要点。
>
> **级别**：用户令「**这个要求作为最重要的规则，落到逐章修订手册中**」→ 本条**优先于其余写作类条款**，取舍次序＝**自足 → 准确 → 优雅**；执行点＝**§0.8 关内清单第 0 行**（任何一关，可单列件逐件剪读，不过即该关未完成）；**不新增闸门、不改红线条数**。

## 一 用户原话

「**所有能够单独表达的内容，如道理、目的、目标、主线、气脉句，还有问题、标题等，他们单独拿出来读，在没有上下文的情况下，能够被理解这句话或这段话所要表达的内容**」。

## 二 触发反例（第13章阶段一，「道理」一句）

我写的：「一份没人写下读法的东西，不会报错，只会让每个接手的人在各自的版本上继续做下去。」
用户点：**脱了上下文，不知道在说什么**。逐字病根五处——

| 词 | 病 |
|---|---|
| **东西** | 空词，什么的一份东西没说 |
| **读法** | 未交代的自造词，读什么、按什么读 |
| **报错** | 借喻（软件术语），且"谁报给谁"没说 |
| **接手** | 接什么手、从谁手里接 |
| **各自的版本** | 什么事的版本 |

改后（过四条判法）：「**一份文件把内容一条条写下来了，还只算写了一半；另一半是"每一条指什么、边界在哪"，这一半不写下来，就由每个接手的人自己当场补一份——几份补出来的各不相干，只在某一天对不上。**」

## 三 规则要点（正文见手册 §2.13）

- **适用范围（封闭清单）**：内涵"一句话"（道理）／内涵四层各句／目的三层／目标（含刻度名）／主线／气脉句／章首几问（逐问）／块题与节题／案例进展题／判据句／图注一句话。**不适用**：段落内承接句、清单条目、附录体例件。
- **四条判法**：① 名词有所指（主语宾语都是能被指认的东西；"这份／那份／它／这／那"不许独立承担）；② 词要有落点（术语与自造词首现在本句里用白话交代）；③ "不够／不对／为什么"落在具体事上（不许停在空词）；④ 抽出来单读一遍（剪出来给没读过本章的人看，他要能说出"这条在讲什么"）。
- **三条施工习惯**：先写"说的是哪件东西、给谁看"再写判断；定稿前把这类内容整批单抄一页通读；一句话里两个"这／那"就地换名字。

## 四 与相邻条款的分界

- §1.1.4 四、⑤⑥ 管气脉句三条（先大白话／自足／取自内涵）——本条是**扩面**，判法一致，**不另立第二套**。
- 风格参考 §6.15 ① 管章首几问的自足——本条把它收进来。
- 风格参考 §6.16 第 1 条（标题要出现本书的词）与本条**并用**：本书的词要用，但须在前序章定义过；本条判"剪出来读得懂"，**不是"把词去掉"**。
