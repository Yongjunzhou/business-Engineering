#### 5.2.3 主线（须支撑本章题目）
> **工程师不是一份头衔，是一份能力清单——第2章那四层结构长在一个人身上，就成了六项能力（科学素养、方法论素养、实践能力、职业伦理，加横切的工程判断与元的可复现意识）；一个物种三种粒度，背的是同一副骨架，账却不是同一本；而能力不中性，方向由职业伦理定。这份能力最终只被一件事检验：能不能开发出高质量的产品数据——换个人拿着它，做得出、接着种得动。**

## 七、能力清单与成长路径（2026-10-09 **已定案**；见 §7.11；产出归阶段三"内容重做清单"）

> **序号与位置**：本节**逻辑序号＝§七**（在 §六 之后），因追加顺序，**物理位置排在本文件 §六 之前**——**阅读按序号，不按位置**（归位留待本文件下一次整体整理）。

> **用户令**：「我们继续讨论工程的能力清单，看看怎么优化，**目标是为希望成为工程师的那些人一个清晰的路径**」。

### 7.1 一处底本偏差（实测，须裁）
**「能力的叠加顺序」本章与底本 11 号不一致**：
- **11 号 §8.2（L500）逐字**：「先有③实践能力（不会做一切都是空谈）→ 再长①科学素养（开始问"为什么"）→ 然后练⑤工程判断（在约束里做取舍）→ 接着有⑥可复现意识（把判断交给别人）→ 最后是④职业伦理……」——**②不在序内**。
- **本章 §9.4.2（L391~398）逐字**：③ → **②** → ① → ⑤ → ⑥ → ④——**插入了②**。
- 判断：本章那一序更像"工程师的路"（动手→把做法变成方法→问原理→取舍→交出去→守方向），且②若不入序，"方法论素养"在路径上无处安放；但**这是改底本口径**，须标明依据或标"本书主张"。

### 7.2 诊断：清单完备，路径散落
现状给读者的，是一张**体检表**（六项能力 → 缺项 → 失败式），不是一条**路线**。路径的零件其实都在，但散在两块四处：
| 零件 | 现位置 | 它回答什么 |
|---|---|---|
| 六项能力清单（四层映射） | §9.2.1~§9.2.8 | 长什么样 |
| 技能四层＋**"哪层是短板，短板往往在下一层"** | §9.4.2 | 短板往哪找 |
| 能力的叠加顺序 | §9.4.2 | 先练什么 |
| 判断依据四档（照做／会选／会取舍／守底线） | §9.4.1 | 深度到哪一档 |
| 拓宽（模块→系统，换轨≠升职） | §9.4.1／§9.3.6 | 横向往哪走 |
| 失败四式＋观察标记 | §9.4.5 | 缺哪一项 |
| 产品数据（按粒度分账） | §9.4.6 | 最终证据 |
**缺的是把这七件串成一条主线的那个东西**，以及两样"路径要件"——**每一站的到达证据**与**入口动作**。

### 7.3 底本已备好、本章未用的三组结构（优化取此处，不必新造）
1. **增量／方向／传递**（11 号 §9 L539 逐字）：「①②③⑤是"增量"（能做事）；④是"方向"（事做对方向）；⑥是"传递"（本事活过本人）」——**比"四层映射"更贴路径**，因为它回答"我缺哪一环"，四层映射回答"这门学科由什么构成"。
2. **知—法—行**（11 号 §9 L540 逐字）：「①回答"为什么能行"，②回答"怎么组织"，③回答"怎么落地"——**三者缺一，另外两个悬空**」——这是一条现成的"缺口诊断"判据。
3. **competence 级定性**（11 号 §7.3 L481 逐字）：*competence = ability to apply knowledge and skills to achieve intended results*（ISO 9000:2026 §3.10.6）；「六项清单属于 **competence 级**——正确用法不是'背知识点'，是逐项自问」——**直接把路径定成"在真实的活上练"，不是"先学完再用"**。

### 7.4 待裁六项
1. **叠加顺序取哪一序**——本章序（③②①⑤⑥④）／底本序（③①⑤⑥④）。建议取本章序并标明依据。
2. **②与⑥是否合成"第一道岔口"来写**——现文已辨"很多人②会、⑥缺"（写得出 vs 主动写）；路径上二者是**同一动作的两面**："把你做对的那件事写出来（②），并且写完就交出去（⑥）"——**石军正是卡在这一步**。建议合成。
3. **是否给六项各配一条"到达证据"**（草案见 7.5）——这是"清晰"的关键：没有证据，路径只能自评。
4. **是否给一个"入口动作"**（希望成为工程师的人，第一天做什么）——草案见 7.6。
5. **"沟通与团队"维持"执行手段"还是升为显式项**——11 号 §7.2 L465／L467 逐字：「ABET 第 3 条…**六项未显式列出——建议补充**」「第 5 条…**建议补充**」。建议**不升项**（升项会破"四层各一项＋横切＋元"的构造，并牵动 ch18"六加四＝十"、附录 A T-25／T-102、案例判词），**但在路径上给它四个落点**（②的可教可学／④的知情／⑤的讲清取舍／⑥的被接住）。
6. **路径落在哪**——建议**重排现第三块那四节**（§9.4.1 拓宽／§9.4.2 叠加顺序＋技能四层／§9.4.3 成长标志／§9.4.4 被任命≠成为）成一条路线，**不新增块**；与第一块首尾相应：第一块答"长什么样"，第三块答"怎么长"。

### 7.5 六项"到达证据"草案（每条＝别人看得见、不是自评；多由失败四式的观察标记反用）
| 能力 | 到达证据（谁能看见、看见什么） |
|---|---|
| ① 科学素养 | 你留下的**预测对账记录**：改动前写的预测与实际偏差、以及"是哪条原理越了界"的结论 |
| ② 方法论素养 | **别人照你写的步骤做出来，结果稳定**（卡住的地方，就是没显性化到位的地方） |
| ③ 实践能力 | 最近一次你**亲手落地**的东西在跑——不是你说过、不是你评审过 |
| ④ 职业伦理 | 你为一件"做了也没人反对的事"**说不**，且相关方知情、有记录 |
| ⑤ 工程判断 | 一个规则没覆盖的取舍：**选了、写了依据、有人知道**（三件齐） |
| ⑥ 可复现意识 | **你休假两周，产线不停**（石军的反面）——换个人拿你的产品数据，做得出、接着种得动 |

### 7.6 "入口动作"草案（第一天做什么）
**把手上最近一次"做对了"的事写成一份可交接的记录（步骤／依据／坑），交给一个同事照做一次**——一个动作同时练②与⑥；他卡在哪一步，就反推你在①（依据说不清）还是⑤（取舍没写）上的缺口。**依据**：11 号 §10 立"能力的最终载体＝产品数据"，本章 §9.4.6 已接；本章 §9.2.3「写 SOP＋看同事在哪卡住」与 §9.2.5「交接演练」现文已有这两个练习，**只是没被合成路径的起点**。

### 7.7 两步落点建议（阶段三用）
① **第一块**（是什么）保留"四层映射"作"**为什么是这六项**"的解释；**增量·方向·传递**与**知法行**放到第三块，作为路径的骨架与诊断判据。② **第三块**写成一条路线：**起点**（能亲手做出来，③）→ **第一道岔口**（写出来、交出去，②＋⑥）→ **第二道岔口**（问凭什么能行、在约束里取舍，①＋⑤）→ **第三道岔口**（知道什么不能牺牲，④）→ **横向的路**（粒度拓宽，换轨的标志＝第一次为系统牺牲自己的模块还觉得值）→ **证据**（产品数据按粒度分账）。

### 7.8 第二处困惑：同章两套清单（用户 2026-10-09 提出）

**实测：困惑不止一种，共四源**（另加一处潜在）：

2. **两套"四层"同形不同物**——ch2 的**学科四层**（工程科学／方法论／工具与实践／价值与伦理，六项能力的来源）与 11 号 §2 的**技能四层**（思维与认知地基／工程方法／技术工具／软技能）。都是四条、都自下而上，**项目对不上、名字也不一样**；读者看到第二个"四层"，会问"那前面那个四层算什么"。

### 7.9 第三问：4+6+4 能不能只留一个数字（比如就是 6）——合理性分析
> **用户原话**：「4+6+4，能不能整合成一个数字，比如，就是 6。我不确定，需要你好好分析其合理性」。

**第一步·三个数字是三种不同的东西**（先分清身份，才谈合不合）：
| 数字 | 是谁 | 分类轴 | 出处 | 与 6 的关系 |
|---|---|---|---|---|
| **4** | **学科四层**（工程科学／方法论／工具与实践／价值与伦理） | 工程这件事**由什么构成**（学科侧） | ch2 §2.3.3（L225~L234） | **来源**：四层各一项（①②③④）＋横切⑤＋元⑥＝6 |
| **6** | **六项能力**（科学素养／方法论素养／实践能力／职业伦理／工程判断／可复现意识） | 那些东西**长在一个人身上成了什么**（人侧） | 11 号 §4.2；本章 §9.2.1 | — |
| **4** | **技能四层**（思维与认知地基／工程方法／技术工具／软技能） | **技能的抽象层级**（训练入口侧） | 11 号 §2 图 2；本章 §9.4.2（**全书正文仅此一处**） | **两轴交叠**：①⑤≈思维地基／②≈工程方法／③≈技术工具／④≈软技能／⑥元——**要靠"≈"才对得上，即两套不同的切法，不是同一套的两种说法** |

**第二步·逐条判"能不能合"**：
1. **学科四层 → 6：可合，但方式不是"删 4"，而是"降为来历、回指第2章"**。四层仍立在第2章（那是它的位置、也是第2章的主线之一），本章**只在一处说清"四层各一项、另加两项"**，之后通篇只说六项。
   **为什么合了不丢东西**：四层的功能（"缺了哪一层，就有一样东西重新落回某个人身上"，ch2 L234）在六项里已经**逐项落成后果**——①缺→换场景抓瞎／②缺→人走方法走／③缺→落不了地／④缺→会出事／⑤缺→有流程也选不对／⑥缺→手艺。**功能留在六项里，四层的"要读者记"就可以撤。**
2. **技能四层 → 6：可合（甲案 7.8）**，且**实测无跨章代价**（全书正文仅本章一处）；它唯一的独有贡献＝**短板律**，改挂到六项内部的层序上即可（③不行看②、②不行看①）。它另一个差异＝把"软技能"显式成一格，已由 §9.2.8"沟通与团队＝执行手段"顶上。
3. **6 本身不能换成 3 或 4**：① **六项是全书既有口径**——附录 A **T-25**、ch18「十项能力清单＝**底座六项**＋增量四项」（T-102）、12 号 §3.6 引"教材书第9章"、11 号 §4.2／§7.2（ABET 对照）、以及两条判词（石军缺**②⑥**／罗建缺**①④⑥**）全建在"六项"上；② 底本 11 号 §9 的"增量·方向·传递"与"知—法—行"都是**三分**，太粗——**逐项自问（六把尺子）与失败四式的缺项定位都会落空**（失败四式必须能指到某一项）。**故 3 不可取，6 不是随手选的数**。
4. **四层本身不能取消**：取消它，"**为什么是这六项**"就失去依据，六项变成"拍脑袋的六条"（与本章术语注"不是拍脑袋列的、以四层为骨架、对照 ABET 七条"直接相抵）。

**第三步·真正的病灶（这一步最要紧）**：读者感到的"数字太多"，不止这三处。本章一口气给了**五组集合**：
`学科四层(4)`｜`能力六项(6)`｜`三种粒度(3)`｜`判断依据四档(4)`｜`失败四式(4)`——再加拟删的`技能四层(4)`。
所以"只留一个数字"的**正确形态不是"把三类结构捏成一套分类"，而是"本章只给一个集合起数字名，其余一律点名"**——这正是 [`00-风格参考.md`](00-风格参考.md) §6.7 的口径（**数字名要拆、清单可以留**；数字只留刻度次序与检查表编号两处）。

**第四步·判定与做法（建议）**：
**合理，但须限定为"本章只立一个数字名的集合＝能力清单"，而不是把三种分类合并成一种分类。** 三步：
1. **技能四层**：删（或降为一句判据，不单列、不进节题）；
2. **学科四层**：降为**一句来历**（回指 ch2），本章不再展开、不再给它一个"四"的名——即**不再说"四层"，改成点名或直说**；
3. **其余三组**（三种粒度／判断四档／失败四式）：**全部点名**（点名三种角色；判断档直说"从照做到守底线"；失败四式点名四式），不进标题、不作数字名。
**效果**：读者在本章只需记住**一个数字——6**；四层是"它从哪来"（一句话回指），粒度是"它用在哪种人身上"（点名），判断档与失败式是"怎么量"（点名）。

**代价与风险（诚实列）**：① 六项若完全脱离四层的表述，易被读成"六条并列的品质要求"——故"来历"那一句与术语注（"本书的凝练，以四层为骨架、对照 ABET 七条，不是任何标准的条文"）**不能省**；② 将来若有章要"从人的能力反推学科四层"，四层的展开仍在 ch2，可随时回指；③ 删技能四层丢掉"软技能"这个显式抽屉，由 §9.2.8 顶上（**须在 §9.2.8 把这条说透，别让它显得是被删掉的**）。

**待裁**：① 是否按上述三步办；② "四层"在本章是否**连"四层"这个词都不用**（全改点名／直说），还是允许保留一处（作来历）；③ 若保留一处，放章首枢纽还是放术语注。

### 7.10 第四问：标准的条数太多——把六项从"六条标准"降为"一条判据的六个检查点"

**三、收敛方案：一条主判据 ＋ 六个检查点 ＋ 一份物证**
1. **主判据（只有一条）＝试金石**——「**换个人、换团队，用同样的需求和约束，能不能交付质量相当的成果？**」（ch2 §2.2.4 逐字；本章已在用）。

2. **六个检查点＝六项能力**——它们不是六条新标准，而是"**接不住**"的六个可能原因；判一个人不合格，只需指出他缺哪几项（现文判词正是这么用的：**石军缺②⑥＝接不住；罗建缺①④⑥＝守不住**）。
3. **一份物证＝产品数据**（终局检验，替代若干条自评）。
4. **其余三组一律降为这条判据的"面"，不再是独立标准**：
   - **三种粒度** ＝ 同一条判据**在三种责任范围上的落点**（换个人接得住的是"我这个元素"／"整个系统"／"结构与演化"）→ 它是"**你在哪一级被检验**"，不是另一把尺子；

### 9.1 第一件·主张（全章唯一，去喻体、去数字；＝本章主线）
> **工程师不是一份头衔，是一份能力清单——而这份清单里每一项，最后只被同一条判据检验：换个人、换团队，用同样的需求和约束，能不能交付质量相当的结果。头衔不定义他，能力才定义他；能力不中性，方向由职业伦理定。**
- **对主线的关系**：主张即主线（手册 §1.3.1 铁规则）；与已定章题「工程师：一份能力清单」逐字相应。
