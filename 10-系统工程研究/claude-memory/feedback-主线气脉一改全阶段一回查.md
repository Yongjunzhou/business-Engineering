# 主线或气脉一改，阶段一其余件全数回查（2026-10-26 用户定）

> **本件是指针件**：规则正文在 [`00-逐章修订手册.md`](../03-架构师是个怎样的物种/00-逐章修订手册.md) **§1.1.4 七**（改口闸门），改版留痕在手册 **§0.4之三 十四**；记忆侧不另记一份正文，只记来历与要点。

## 一 用户原话

「**这里有一个规则，如果主线或气脉句调整，则需调整第一阶段的其他内容，需要落入逐章修订手册中**」。

## 二 为什么单立一条

主线与气脉是阶段一的两根梁，**其余五样都挂在梁上**——梁换了、账还是旧的，交出去就是一份自相矛盾的展示件。

**第12章实测（2026-10-26）**：主线一日之内三改（稿4「能被重新走一遍的依据」→稿4改「哪几条／凭什么留／谁认下的」→稿7「时差」→稿8「定稿」）。每次改动，主笔都只改那两句；**用户追问「基于此，第一阶段的其他内容要不要随着调整？」后回查，查出七处要跟着改，其中两处当场已是硬伤**：

1. **内涵"一句话"被顺手写成新主线的同义改写**——抵触 §1.1.3 口径 6（一句话＝道理，主线＝主张，不许同一句）。改法：一句话退回"道理"层。
2. **"可撑"那一句的块↔层映射仍按上一版的内涵四层配**——四层内核由"三样同时在最坏的位置"换成"时差"后，原映射整条作废。

另五处：目标里仍引被弃稿的提法（"凭什么定下来的是这一个"）／兑现①之后的新问题把读者送回前一块（"那几个可选的怎么比"）／内容概要漏了主线的第一句（"往往没有一个是全满意的"）／块四只列记录有哪些项、没写"为什么必须有"／主线新落点（"决策要的不是选对，是错查能出来、改得起"，38 号 §10.2 定性）未登记进 §1.5 第 0 步的"本书读法"清单。

## 三 规则要点（正文见手册 §1.1.4 七）

**规则**：主线句或气脉句一经改动（**不论由谁提出、改动几个字**），阶段一其余件**必须逐件回查并留痕**，不许只改那两句就交。

**回查九件**：① 内涵四层（含"可撑"映射）② 内涵"一句话"（是否与主线同义）③ 目标（有没有引用旧主线原句、新主线的心智落点有没有进）④ 气脉一页（两者是否仍不同义；三处兑现与其后新问题是否还接得上）⑤ 内容概要（主线每一句都要有一簇接住）⑥ §1.5 第 0 步的"本书读法"清单 ⑦ 定死项（新主线带出的用词禁令）⑧ 待裁理由（若用了旧内涵的映射）⑨ 落选稿登记（被打回的稿与病根）。

**三条最常留的硬伤**：① 内涵"一句话"与主线同义；② "可撑"映射按旧四层；③ 兑现后的新问题把读者送回前一块。另两条：目标里仍引旧主线原句、主线新句在内容概要里无对应簇。

**留痕格式**：入口文件阶段一节内单起一行「★ 同日第 N 次修订」，写清"**连带改了几处、哪几处、哪几处查过不动**"。

## 五 与相邻条款的分界

- §1.1.4 三、四（内涵闸门）管"**先想透再出句**"（出口）；本件管"**句改了要回查**"（改口）。
- §0.5 纪律 6 管"**停不停、谁给确认**"（关口）；本件管"**关口前那份展示件自洽不自洽**"（关内）——故**不并入纪律**，否则"回查"会被读成"再停一次"。
