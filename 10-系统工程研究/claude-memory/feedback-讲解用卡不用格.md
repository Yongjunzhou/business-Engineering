# 讲解用"卡"不用"格"

**用户原话（2026-11-04）**：「用卡比格更容易接受」。

**边界（2026-11-04 已裁决）**：用户令「改」——48 号正文、§0.4、标题与文件名均改称「卡」（「第N张卡」「二十张卡」；文件名改为“……二十张卡产品数据转换.md”，git mv）；原“因子格”“三格分流”及一切单元义“格”也一并撤，改“因子”“三去向”；词内之“格”（合格/规格/风格）不在其列。
