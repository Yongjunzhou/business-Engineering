# 分层以三到五个子项为限（把控感）

> **性质**：**用户裁定的写作与分层判据**（2026-10-16，起于第16章阶段一"49 条任务"一处）。**用户原话**：「**一个事项三、五个子项，对我们还行，再对就没有把控感了**」。

## 一 口径

1. **限量**：凡向读者**同时交代**的一组并列项（清单／表／活动组／判据组），**同层子项以 3~5 个为限**——**一个事项配三到五个子项**，是"还拿得住"的宽度。
2. **超限即再归拢一层**，**不许继续平摊**：超过 5 个，先归成 **3~5 组**，各组再展开；组内仍守 3~5。
3. **判据是"把控感"，不是"完整度"**：**长清单不等于分得细**。把 8、11、14、49 个条目直接摊给读者，**等于没分**——读者拿不住，也就等于没交代。
4. **归拢须标来源状态**：若被归拢的是**标准正本**的既有分组（如 42020:2019 §6.4 的六项活动），书上要写明"**这是本书的归拢**"，并把**正本的分组名逐字给出**；不得让读者以为正本就是这么分的。
