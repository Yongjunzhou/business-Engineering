# 规则：库与本体不分家

## 一、规则与来由

用户先问「为什么有相关方需求库？」，再裁**「相关方需求本身就是库」**，随即把它定成规则：**「库和本体不分家，这是一条规则」**。

一份产品数据的条目、号与登记，就是下游按号取用的那份库。它之外不另立一册「需求资产库」。

## 二、三条判法

一是问条目有没有第二个本体。没有，它就长在自己那一册身上，不另立库。
二是问取的那一份与要写的这一份是不是同一份。是，它属底料与承值，不记成「取来的资产」；否则资产线自己喂自己，一笔账记两回。
三是问取来的东西指不指得到户名与条号。指不到，就是无本体，退回。
