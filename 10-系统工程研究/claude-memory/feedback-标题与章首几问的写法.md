# 标题与章首几问的写法（2026-10-21 用户令落库）

## 一、用户怎么下的令

1. 「标题应该体现本书的内容框架，读者一看就知道这一章的内容，还能支撑本章的目的、目标和主线。当前的版本差距太大」
2. 「17.2，这里的七处、四段、三样是什么？标题需要再明确一些，比如，一张清单，是什么清单」
3. 「需要你对标题进行重新构思」→「你再好好构思下」
4. 「好像还不如之前的方案好呢」（把我改成章十句式的八道题否掉，退回他自己那一稿）
5. 「但标题中少了架构相关内容」→「应该在设计之前立架构，在后面再用治理」→「四段和三样似乎是失效了」
6. 「本章的四个问题，还是第十章那几个问题当初的毛病」→「问题不完整，看不懂」→「走不完的时候，它通常断在哪儿？……谁走不完？接上之后，什么接上之后？」
7. **「这些要求在相关文档中缺失了吗」→「对，在风格参考和逐章修订手册中，要落进来」**

## 二、落到哪儿（已落）

| 规则 | 落点 | 内容 |
|---|---|---|
| **§6.15 章首几问** | `00-风格参考.md`（v1.27） | 四条：自足（主语宾语是名词）／不靠上下文／**不是目录的问答版**／覆盖到章末件；附两条机械可查 |
| **§6.16 标题即框架** | `00-风格参考.md`（v1.27） | 四条：出现本书的词／数词不裸用泛名词不泛用／几题连成一条链且异类句式错开／**数量随内容定不为凑数改内容**；写明与 §6.8 四律的冲突裁决（先保本条） |
| 工序第 5 步＋两条教训 | `00-逐章修订手册.md` §0.0之二 | **章首几问在动笔之前过一遍 §6.15**；教训③标题数不为凑数、④**图≠路**（分类图与真实顺序相抵时，把图当分类、走路按硬时点，并明写"图是分类用的，不是流程用的"） |

## 三、判据（复述用）

- **标题合格线**：把块题单独抄成一页给没读过本章的人，他能说出"这一章讲什么"，且题面里有本书的概念名。
- **几问合格线**：每一问能单拎出来读，主语宾语都是名词；抽掉上一问仍成立；不把块题改写成问句；问到全章最后一块。

## 四、这一轮的坑（按此防复发）

① 题里一个本书的词都没有（"跟着走一遍／断在哪儿"）→ 读者不知道讲什么；
② 数词裸用（"七处／四段／三样"）与泛名词（"一张清单"）→ 读者要问"是什么"；
③ 只学章十的句式、不学它的自足 → 问句里"它/这/那"乱用；
④ 为凑标题数把内容并块 → 内容被削，用户当场否；
⑤ 分类图与实际顺序硬凑 → "四段是三样"当场失效，正解是图≠路。

## 五、规程提醒（下次写别的章照办）

1. 先定内容分块（几块由内容定），再起标题；
2. 块题先满足 §6.16，再看 §6.8 四律，四律的例外逐条登记；
3. 章首几问在**动笔之前**定稿并过 §6.15（问句一改，引言段与末段回扣都要跟着改）；
4. 骨架里凡有"分类"与"顺序"两套东西，先写清哪张是图、哪条是路。
