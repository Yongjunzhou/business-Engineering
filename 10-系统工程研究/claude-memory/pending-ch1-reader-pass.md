## 五 丁 大手术：1.3 重排（单独立项）

**理由**：1.3 占全章 24.7%，是最大也最干的一块；三个示例（阻抗／产品开发／产品数据）是全章最具体的内容，却压在最末尾；而 ISO 1087 的「概念」定义与「名字／意思／东西」三角插在「三层」与「根概念」之间，把「哪几个概念承重」这条链打断。更要紧的是**手法不一致**：1.4 自己声明「先见后名（先逐级给例子，再用总表命名）」，1.3 却是「先名后见」。

**现序**：故事 → 三层 → 什么是概念（ISO）→ 来源／共识 → 根概念 → 核心概念 → 原理 → 找法 → 三示例 → 跨域换位。

**议序**：故事 → 名字／意思／东西（就地解释两场会为何吵）→ 共识非真理 → 三层 → 根概念（定义＋四判据＋三条理由）→ **示例①阻抗就地过四判据** → 核心概念（枢纽）→ 找法（第 0 步＋三步，用阻抗走一遍）→ 示例②③ → 跨域换位。

**收益**：第一个具体例子从 85% 提前到 40% 左右；「什么是概念」紧接两场会，正是读者此刻的问题；甲乙两处硬伤（#2 枢纽／根概念、#5 桥句）在同一批里落掉。
**成本**：≈1 日（含复算与冷读）；连带 `00-目录` 不动（无新标题）、`19-附录` T 系列不动、附录 A 总图内部次序微调。
