## 1 适用范围与两层文字

### 1.1 管的内容

管五类产出：研究报告、教材书、培训教材、产品数据、产品数据规范。管的是题面、表外散文句、正文措辞与格内成句；不管内容对不对、字段全不全、追溯接不接得上，那些归各规范与规程。

各章的适用范围见目录。第 12、13、14 章只管产品数据与管这些数据的规范，其余各章五类同用。

### 1.2 两层文字

同一份文件里有两层，尺子不同。

**格内判据句**：字段的写法、不成立、判法、处置。短、硬，一句一个判，不带表情。判据句不为口语化改虚；短是它的本分。

**表外连续行文**：概述、章引言、节与节之间的过渡、附录说明。按说话写：有人在做，有动作，有先后，读的人顺着往下走。

两层混用会出两种病：判据的短硬搬进连续行文，读起来是一张张卡片，拼不成话；行文的松散搬进判据格，判据就判不动。

### 1.3 判据句不按三问判

判据清单、引文、表格、章末查阅件（附录、总图、参考文献）不受第 3 章三问管：读者是来查的，不是来读的。但总判与第 4 章清单对它照样有效。

## 2 总判：说得出理由

**每一处写法，都要说得出内容上的理由；只能说出「上一句就是这么排的」，就是腔。**

人写的时候，长短、省略、词序、停顿是被内容逼出来的：他知道这个数要砸下来，所以那句只留四个字；他知道读者会在这里卡住，所以断成两句。机器写的时候，选择是被上一句的句法逼出来的：上一句三项，这句也三项；上一句对举，这句也接「而是」。

改动还是不改动，只回答一句「理由是什么」。答得出，保留；答不出，就改动。

**两条禁手**：① 不许按病型下刀——「三项必须改两项」「长句必须切短」这类命令，一律不认；② 不许把判断说软——腔的改法是把话说回具体，不是把话说得含糊。

## 3 一段有没有腔的判法

### 3.1 病象三问

一段话，是一个人在跟一个人说话，还是在向档案柜报告？

**表3-1：病象与判定**

| 问的名字 | 问的写法 | 判定的结果 |
|---|---|---|
| 一 看得见吗 | 这一段有没有一样能指认的东西：一个人、一件物、一个数、一句原话 | 一样都没有，是腔 |
| 二 有人说话吗 | 有没有语气、评价、犹豫、一句口语 | 通篇公告，是腔 |
| 三 要回头吗 | 有几处要读者回头找前件 | 超过两处，是腔 |

三问里两问答「是腔」才立案。改法三句：把名词换成动作，把回指换成点名，把结构交代换成一句现场的判断。

起步动作是「搬进」，不是「删减」：先搬进一个能指认的物（一张单子、一格空的、一个人说的那句话），再动手删减。删减是在空气里做减法，越删越空。

### 3.2 读者不停下来

读者不停下来。一句接一句有推力，段末能落地；读者不用回读上一句补主语，不用数前文的「三样」「那六条」。句子太长、指代没有着落、压缩词没有摊开、段与段之间没有桥、段末没有落点，这五样都让人停下来；见一样，改一样。

### 3.3 成串才判腔

单发无罪，连发即病。达到下面的阈值才立案，单发一律判留。

**表3-2：成串立案的阈值**

| 命中的形 | 立案的阈值 |
|---|---|
| 等长三连 | 同一段两处，或相邻三段三处 |
| 破折号 | 相邻四段四处 |
| 判断式 | 同一段两处 |
| 短断言起头 | 连着三段 |

## 4 句级清单

一条一行：长什么样，改成什么。清单只管「一句话读着顺不顺」，判据对不对另由各规范管。

**表4-1：句级忌与改法**

| 忌的名字 | 长的样子 | 改成的样子 |
|---|---|---|
| 自造引号词 | 「独立留痕」「允许客户改的那一格」 | 行业实词直说：运输段没有独立于承运方的温度记录 |
| 自造简称 | 「收判例」「沉淀条」「回改判据」「册升版」「落打回台账」 | 说全这句话：把评审挑出的错记进判例库；规程改版；记进打回台账 |
| 排比模板 | 三行同以「差在××这一环」收尾 | 每行按事实用自己的说法 |
| 元话语 | 「★ 必须点破」「一句：」「本轮只立三样」 | 全删，直接说 |
| 粗体轰炸 | 几乎每句加粗 | 只加粗编号与关键词；加粗不超过 6 块每千字（第 9 章） |
| 破折号引总结 | 每格「：…；…都无从立足」 | 这种用法删掉；破折号整体按第 9 章的线 |
| 对仗口号 | 「料在、形态不在」 | 改成陈述句 |
| 对偶口诀 | 两条规定压成两个四字短语并置，不出主语，也不说落在哪一格：「一行一个岗，写到岗不写出人名」 | 拆成一句话，把谁在写、写在哪一格补出来 |
| 索引句 | 一个短标签加冒号，后面串一长排名词短语：「下游五处按号来取：文档3 的「来源」字段、文档4 的确认准则来路……」 | 冒号后每一处补一个动词，说清谁对什么做什么 |
| 先报数再填空 | 一段的头一句先报数目，后文逐项填进：「料从三处汇总。一处是……」「表间挂靠三处。」 | 先讲事，把数落在句子中间，或直接点名目：三张数据表之间靠号连着 |
| 单字的名词与动词 | 「栏与不成立判定照卡写」「本册照着写」「数据照它撰写」 | 名词写全：号写编号、件写文档、格写数据项、册写规范、栏写字段、卡写 48 号卡、名写名称；动词写全：判改判定、写改写出、改改动、核改核对、列改列出。只作量词的可以留：一条、一份 |
| 行话与名词化作动词 | 发的不是概念／两句话收束／先抓对词／口径（＝说法）／落点（＝落在哪） | 不给你一个新概念／两句话说完／挑对该先说准的那个词 |
| 指代多候选 | 一句里「它／这／该」回头三行，有两个以上接得住 | 把所指的那个量名补出来，一处指代只留一个候选 |
| 比喻 | 借画面说事：乐队／单向门／体检／戴着镣铐跳舞 | 先试直说；直说到底，才准用，且一经命名就止。四问：帮读者拿到新东西吗、拿掉还能拿到吗、是唯一的名字吗、有判据、有定义、能复核吗。一章并用的比喻系统不超过四套。熟语式承重命名（试金石）不算活比喻，但不进标题、不写画面句、首现把判据说全一次 |
| 啰嗦 | 加粗通胀、同一判断正说三遍、判据后接「解释＋例子＋总结」四段式 | 一个判断只正说一次，其余作回指；加粗只标关键词；判据后只附一个违反后立刻出事的例子 |
| 例子不指认 | 一段里没有一个能指认的实物、一个会变的场景 | 一个实例贯穿；第二个例子只在换行当、换维度时出现 |
| 旧版残留 | 「原写作……」「已撤」「此后按它判」 | 正文只写现在是什么；沿革进版本记录或台账 |
| 一句一段 | 同一件事拆成三段，每段一句 | 按一件事并回一段；段超过 200 汉字才拆，拆开也按事情分 |
| 括号装内容 | 括号里写解释 | 括号只放指针；解释进正文 |
| 英文不在列 | 只给英文或只给中文 | 英文与中文在列；逐字引文紧随「（中译：…）」 |

### 4.1 一句话站不站得住

清单是样子，这四条是尺：

1. **判据句与规定性句子，每句都能判定对错。** 判法要写清查看哪一格、数什么；写不出判法的句子（「应当重视」「要充分」）不进正文。叙述与举例的句子不按这一条判。
2. **一句话一口气读懂。** 一个判断写成主—谓—宾的短句；绕两个弯的从句拆开；括号里不再套括号。
3. **一句话只推进一件事。** 两件事就分两句，或用「因为／如果／等到」把因果接住。
4. **专业与易懂在同一句里成立。** 术语该用就用，但读者要在同一句里拿得到它：术语首现能答「它指哪样东西」；一句只放一个判断；判断有落点。不专业的样子是自造词当术语、拿比喻当定义、含糊；不易懂的样子是压缩过度、指代空指、行话堆叠。

### 4.2 压缩词的分级

章内自造的简称、数字名、喻体名，指代一组内容，而成员不在紧邻处。按第几次用，分三档：

**表4-2：压缩词的分级**

| 档的名字 | 用的位置 | 判的依据 |
|---|---|---|
| 一 首现可压缩 | 第一次真正被使用的地方 | 解释紧跟其后：同句或紧邻句把成员摊开 |
| 二 复用须自足 | 首现之后每一次使用 | 要么把词摊开成自明的一句，要么整句不依赖它；不许只丢一个压缩词就走 |
| 三 章末查阅件只报名字 | 附录、总图、参考文献 | 读者是来查的，摊开反而伤检索 |

### 4.3 不以数代名

数字只留两处：它本身就是刻度或次序（能力四级、第 ② 级、年份），以及必须逐条打勾的检查表编号。其余一律点名，不给集合起数字名。清单可以留，数字名要拆。

### 4.4 白话优先

凡是读者要停下来想一下才明白的词与句，都换成日常说法。术语留，行话去：有定义、能复核的词保留，但首次出现要用一句白话讲清；无定义的口头行话一律换掉。

## 5 段落

- **一段装一件事**，事情换了才分段。
- **每段不超过 200 汉字**，越线才拆，拆开按事情分。
- **段中位、短段占比、短段成串一律不设线、不报数**；段落长度只守 200 这一条。
- **并段只并段界，句读不动**：两句本以句号断开的，并段之后仍以句号断开；改成分号，两三句并作一句，句中位当场破线。并完复算一遍句中位，破线就拆回句号。
- **段的头一句不报数**：先报一个数、再等分项，读者像看一张贴了标签的卡片。要么先把事说出来、把数落在句子中间，要么直接点名目。
- **同段不连发同一句式**：连着三句同头必换法；排比只在内容真对举时才用。

## 6 标题与列名

题面四处：章题、节题、表题、列名。同一把尺，尺度按标题与列名各自定。

### 6.1 标题的三道关

次序不可颠倒：

1. **读者关**：把一页标题单抄出来，给没参与编写的人读；他读不出这一块讲什么，整组重拟。不许对着判据清单打勾。
2. **形式关**：十项逐条过，加题面三不许。
3. **名实关**：正文定稿之后过，核标题与内容对不对得上。

**形式关十项**：

**表6-1：形式关的项与不过的样子**

| 项的序号 | 项的名字 | 不过的样子 |
|---|---|---|
| ① | 实词起首 | 以「四构件：」「归零项一：」这类清单标签起首 |
| ② | 不带符号 | 出现 vs／≠／⊃／＝ |
| ③ | 不用喻体 | 以画面命名，或术语入题指不出逐词裁定 |
| ④ | 有户口 | 题面词既非日常话，又没有条目 |
| ⑤ | 不带工序名、位置名与指代 | 出现「第一次」「前移」、四问名、代词；代词按族列全：人称、指示、疑问、无定、相互；疑问词不坐承重位 |
| ⑥ | 不带数字 | 出现数字名，或数词加量的纯代称（「哪一份」「这一份」）；年份与版本号不算 |
| ⑦ | 不超过十五个汉字 | 只数汉字，编号、标点、拉丁字母、阿拉伯数字不计；超一字即不过 |
| ⑧ | 显性支撑上一级 | 写不出带的是上一级题面的哪一个词；填评价不算 |
| ⑨ | 同一层同一句式 | 同一块的各节不同形；错开未在该行备注写明理由 |
| ⑩ | 不用单字的名词与动词 | 出现单字名词（号、件、格、册）或单字动词（取、写、看、改、记、标、挂、判、核、拆、列）；只作量词的可留 |

十项管章题与节题；表题按 6.3，列名按 6.4。⑧ 是教材书章题与节题的要求，其他文档这一项不判。

**题面三不许**：自成一个判断，疑问词不坐主位；代词一律不进题面；动词短语要带宾语。

**谓语的选法**：宾语是可用的东西（一个概念、一套判据、一把尺子），用「怎么用」；宾语是要做的一件事（一个过程、一项活动），用「怎么做」。「用」配工具与词语，「做」配活动，配错即范畴错。标题不带问号。

**标题四律**：不出现数字；不出现喻体；同一层同一句式；不超过十五个汉字（只数汉字，编号、标点、拉丁字母与数字不计）。第三律是教材书的要求；其他文档同一层用同一种写法即可，不强求同句式。

**读者关三步**：① 换身份，放下作者身份，假装第一次翻到这一页；② 连着读，把这一块的块题与它下面所有节题连起来读；③ 复述并记卡点，读完用自己的话说一句「这一块讲什么」，说不出口、要补字、要猜词、要回看，都算卡住。

**易懂五条**：① 读一遍就明白这一节讲什么事；② 不出现书内行话与工序名，只在元文件里出现的词不进标题；③ 补充位说「这一节讲什么」，不说「它算第几步」；④ 不必读过别章就能读明白；⑤ 题面不靠上下文的指代，凡「那一份」「那几件事」「这一版」一律换实词，疑问词不坐承重位。

**名实关四项**：① 名实相符；② 不与正文首句重复；③ 与主线对表；④ 扫全库引用，目录、框架、训侧、脚本锚点。

**常见卡点八条**：

**表6-2：读的时候卡在哪**

| 卡住的地方 | 举的例子 | 改成的写法 |
|---|---|---|
| 动词没有宾语 | 造出来，判出来 | 写出宾语：做出方案，判出好坏 |
| 宾语认不出 | 管的范围不同 | 管一块、管整个、管架构 |
| 两个端点不同类 | 从需求到版本 | 端点同类，或改陈列动作 |
| 术语压成动宾，退回成比喻 | 造树／换路 | 降回原词：造方案／换的是范围 |
| 否定不给正面 | 发的时候不看活 | 跟出看的是什么 |
| 给人贴物的标签 | 会写代码、会画图，都是工具 | 主语换成动作 |
| 一物多名 | 正文写「事」，题面写「活」 | 跟正文走 |
| 未交代的器具名 | 格子／表／栏 | 目录上没有那张表，就不许用 |

### 6.2 剪出来读得懂

一句话或一个题，剪出来单读，没有上下文也读得懂。

量词单独顶在名词位，如「一处」「一格」「这一条」，不算自足，要把那个量名补出来。一串名词短语排开交代去处，也不算自足：冒号后接三个以上的去处，每一处各自要带动词，说清谁对什么做什么。

表题同过这一条。格内是取值，一个值、一个号、一个词，不按句判；格内是句，即判法、处置、说明、反例、一串名目，剪出来单读，读不懂即不合格。

### 6.3 表题的写法

只管数据与规范。

一张数据表的题写出一行，形如「表3-1：……」。表题里不出现数目：行数会变，数写进表题，数一变表题就假。也不写「取值」「一览」「说明」这类什么表都套得上的空话；表题要答出这张数据表装的是哪几样。上限十五个汉字，实际控在十一二字以内。

### 6.4 列名的三道关

管所有表格的列名；取值域、单位与别名那句只管数据与规范。

1. **读者关**：把一张数据表的列名竖抄成一列，给外人读；读不出这个字段在量什么，整张数据表重拟。
2. **形式关**：六项逐项过。

**表6-3：列名形式关的项**

| 项的序号 | 项的名字 |
|---|---|
| ① | 名词短语，不用问句、不用动词句 |
| ② | 不用代词族（这、那、该、本、各、其等），不用「同上」之类回指 |
| ③ | 不带括注、数字、符号；取值域、单位与别名写进节首一句 |
| ④ | 不用比喻、内部代号、工序件名 |
| ⑤ | 四到八个汉字，最好不超过六个 |
| ⑥ | 一张数据表之内一列一义、一名一义 |
3. **名实关**：正文定稿之后逐列读十行值，核列名与格子里的值是不是一回事。

**列名即判据名**：列名要说明这一列量的是什么，判据依它成立。**取名四步**：一问这个字段量的是什么，是一个量或一件事；二选那个量的名词；三压到六个汉字以内，压不下最多八个；四把取值域、单位与别名挪进节首一句。

**长度只留两类例外**：一是已定的中文字段名，两三个字的照原样不改动；要改动须卡、规范、数据三处同批。二是表头的序号列，当作序号用。

**过半重拟**：一张数据表里过半列名不合格的，整张数据表列名重拟，不许只改动一两个；改动法是退回重拟列名，不动格子里的取值。

### 6.5 节题的取名

节题取名优先选用所属文档的章题。两处不同名时，在附录 A 或版本行写明哪个名对哪个名。

件名与题名的分家见第 12 章。

## 7 各处位置的写法

**表7-1：各类位置的写法**

| 所在的位置 | 写成的样子 | 判的依据 |
|---|---|---|
| 格内判据句 | 短、硬，一句一个判；写清查看哪一格、数什么 | 按该字段的写法与不成立判 |
| 表外连续行文 | 按说话写：有人在做、有动作、有先后 | 过三问与第 4 章清单 |
| 表内取值 | 一个值、一个号、一个词，不按句判 | 不量句段尺 |
| 题面 | 章题、节题、表题、列名 | 三关与自足 |

## 8 可以不改的写法

- **量词可以留**：一条、一份、三处、两条。
- **书名与固定名可以留**：《逐章修订手册》、48 号卡、24 号。
- **固定词可以留**：「判不过」「以卡代册」「占号不占行」，都不改字。
- **判据句短硬**，不为口语化改虚。
- **引文照原字**：引用别处原句，照原字抄录，删节处以省略号标出；别的规范里的句子可作参照，不得挪用。
- **正文不写前序版本**：原写作、已撤、此后按它判，都不进正文；沿革进版本记录或台账。

- **术语用全称，不单用简称**：术语位一律写全称；单字简称只在构词与固定说法里出现。
- **书里不写考据**：「正本不在库」「转引自某某」属内部证据等级，只进原料清单与记忆；正文只留可查的出处。
- **定义块里的多条判据逐条立**：定义句一行；判据另起一行，一条一行，不塞进括号。
- **加粗的收尾**：句读落在加粗之外（`**小标**。正文`），英文括注也落在加粗之外；改完跑一次核对器。

## 9 脚本只报不改

五只脚本：量尺、单字、对偶、列名在 `00-文风优化工具/`；交稿体检在 `04-产品数据范例/`；标题在 `03-架构师是个怎样的物种/`。定位是**筛子**，不是判据。

- **只报不改**：脚本报「这一句是那种形」，改动还是不改动由人按第 2 章判。
- **读数不作刀口**：破了线，回去读那一句；不按读数下刀。
- **单发判留**：成串才立案；脚本报出来的形（腔的五型、对偶关的六类）只作症状表。
- **改后复跑**：改前用来找嫌疑人，改后用来验证。

## 10 规则只在这里立

1. 文风判据只在本文件立；其余文档只指过来，不重写条文。
2. 新毛病先往第 4 章清单添一行；同一个毛病出现三次以上，才立条文。
3. 每立一条，写清四样：长什么样、改成什么、判法、例外。
4. 样本、配比、施工步骤、脚本口径不进本文件：样本在《风格参考》，施工在两本手册，脚本在 `00-文风优化工具/` 与 `04-产品数据范例/`。

## 11 施工纪律：逐段逐句

按本文件改一份文档时，段落只用来分组，判以句为单位。

1. **一段之内，从第一句到最后一句逐条读。** 不得整段目测，不得跳过任何一句，不得拿段首与段尾的印象代替中间的句子。
2. **每句落一个处置。** 判改的写出改后；判留的写一句为什么。没有处置的句子，视为没读。
3. **每段交一张句子清单。** 四列：句序、原句、处置、改后或判留理由。一份文档的每一段都有清单，才算走完。
4. **表格按格进场。** 成句的格逐格判；取值格不按文风判，但要标「取值，判留」。
5. **改完复读一遍。** 从第一段第一句读到最后一段最后一句；读不顺处回改。

**为什么单立一条**：整段看会漏句，也会按上一句的句式顺手改下一句；只改显眼的那一句，剩下的就漏了。逐句过一遍，慢，但一遍抵三遍。

### 11.1 优化的次序

读的时候从头到尾；改的时候，先小后大。

**次序不可颠倒。** 每一步交一张施工单，写清动了什么、证据是什么、过没过闸；过了才进下一步。后一步动了前一步的对象，例如风格改写碰到了字段名，退回前一步重过。施工单模板见 `00-文风优化-施工单-模板.md`。

**每步先出临时文档。** 每一步的方案或结果先写进一份临时文档，内容贴出来给人看；讨论确认后，才走下一步。六步各一份；第四步内部的五小步，也各一份，名作第4步-1-段落骨架.md 至第4步-5-复读.md，排在同一目录下。全部走完，删掉临时文档与所在目录。临时文档放在 `.ai-agent/work/文风优化/<文档名>/`，不入库。临时文档里贴改前改后，不写「已改」；证据指到句、格或表号。

1. **表号与表题**。先给表一个名字，后面的字段与文字才有归属。
2. **表格字段名**。正文会引用字段名，先定名，正文不用返工。
3. **表内文字**。格内成句，按字段名判。
4. **表外散文**。段与句，按 11.2 的次序走；引用的是已经定下的字段名与表号。
5. **各节标题与章题**。标题概括正文，正文没定，名实关判不准。
6. **并段，再从头复读一遍**。并段动段界与句读，放最后。

次序的理由只有一句：被引用的先改，引用的后改；概括的后改。反过来做，改过的句子要跟着字段名再改一遍。

### 11.2 表外散文的次序

1. **段落骨架**。一段一件事，事情换了才分段；这一层只分段，不并段。
2. **句子骨架与风格**。按数学之美改：从问题起，一句话说到底，数量级落地，口语判词一节至多一句；同时过 4.1 的判据，一句话只推进一件事，一口气读得懂。
3. **腔的清理**。排比、对偶、报数、元话语、破折号、索引句。
4. **词层清理**。单字名词与动词、压缩词、指代、数字名、行话。
5. **复读与复跑**。从头读到尾，读不顺处回改；跑单字关、量尺、对偶关。

为什么风格在前、词层在后：风格改的是句子的排法，词层是替换。先改排法，再换词，句子不用动第二次；反过来先换词，风格一改，新句子又长出单字与压缩词。

**开始一份文档时，粘这一句：**「按《文风与表达规则》11.1、11.2 的次序改这份文档，每步交施工单，过闸才进下一步；后一步动了前一步的对象，退回重过。」

## 12 文件的自称与件名

管产品数据与管这些数据的规范。

- 规范指自己，写成「本规范」。
- 被管规范指正在写的那一份，各节一律这样称呼。
- 数据本体不写自称：写表号或「这里」；不写本份、本表、本登记册；不带号形；不写「本文第 5 章」。
- 一个文件只用一个自称。规范这一侧，本规范、本份、本文三种混用即不合格；数据本体那一侧，出现任何自称都不合格。
- 编制规程的件名（户头、资产三问、承接档、验收判定、节末一行）不进数据本体。
- 不用自指替先行词。
- 工序里的件名与数据文件里读者所见的题名，是同一件的两个层次，不得混用。件名只在编制规程、工作件与台账里出现；数据文件里读者看到的那一行，一律用自足的名称。

## 13 判据句的写法

管产品数据与管这些数据的规范。

1. **判据句先过 4.1 第 1 条。** 另加一条：查看来源不是判法，查看来源格中有无记录名与部位才是。写不出判法的句子，例如应当重视、要充分，不进正文。
2. **判法用自己的话写出。** 判据的正本在 48 号卡上。写出的，是这条规则用在某一个字段时查看哪一格、数什么，须用自己的话；48 号卡上那句原样搬来，即算抄。卡号写在转换表的最后一个字段：将来 48 号卡改了，可依卡号确定应改动哪一条；写错了，也可依卡号回查。
3. **字段名与数据逐字一致。** 同一份规范中两张数据表用了同一名称却表示两义的，改名，或者在第 1 章末那条分界里写明两处不同义。
4. **规范不载数据。** 不出现真条目、真取值；需举例时只指路，写出「见某份数据的某一节」，不得把那张数据表抄进来。
5. **篇幅取决于四样齐备**：字段表三列、验收准则含合格条件与处置、转换表覆盖全部字段、编号三件。四样齐备即可，长短不限；行数不必记录，也不据以退稿。
6. **数量与序号的写法。** 数量用汉字，三到五条；序号用阿拉伯数字，第 2 条。数目不写死：判据里那个数不是判据本身时，写出多个、多条，不写出两个、两条。

## 14 数据专有的写法

管产品数据。

- **取值带单位**：12 周、−18 °C；≤、%、℃ 一类符号不进题面，正文也不拿符号代字，写成「不超过三天」。
- **示例值要标**：真值不能充当示例；正文处数、示例值登记行数、来路里标示例值那几行，三处对齐。
- **格内成句要自足**：一串名目剪出来读不懂的，补件数、补谓语；括号只放指针。
- **判据格不写成散文**：短、硬，一句一个判，写清查哪一格、数什么。
- **表内取值不量句段尺**，也不用同一个例子连演三遍与口语判词；一格只装一件事。
