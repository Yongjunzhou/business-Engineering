# 方法论的底座：全书方法论的底色、理念、思路与方法

> 本书方法论的 DNA——第1章是它的示范章，本文件点明其四层，并为每一层配一套**框定问句**：用它可以框定/审视/修订任何一章。审查镜由此而来，不每次临时磨。
>
> 版本与结构权威见 `00-全书框架.md`；案例细节见 `00-案例设定.md`。
>
> **怎么用本文件**：写新章前，对着四层起草（先立枢纽 → 钉概念 → 判据/自查/练习在掌握线之上 → 案例落实践）；审既有章，对着每层"框定问句"逐条过；**重构既有章（结构未对齐时），按 §六 重构方法**；过完，落到 `00-全书框架.md` §五 七块模板 与 三道自检。

## 一、底色（根本预设：给全书染色的那层）

- **三重祛魅**：反记忆崇拜（懂≠记住，会背只是"见过"）／反天赋论（能力是练出来的，有五环流水线）／反绝对真理（概念是共识不是真理，枢纽可修正）
- **判据主义**：不给没有判据的定义、不给没有失效边界的工具、不给没有反例的概念——"不是什么""往哪去"（失效边界）比"是什么"更见功力——且判据要配"违反即崩"的画面，让失效边界可辨认
- **意义即用法**（维特根斯坦）：概念的意义在用法里；用"它做什么"定义"它是什么"（功能判据为主——核心/根概念用功能判据；全集"概念"本身用结构判据以便可判定）
- **谦逊诚实**：给边界、给失效、不把话说满；每一章自己践行自己教的判据；区分"陈述共识"与"作者主张"，让"概念是共识"可对账
- **人本定位**：AI 时代记忆已外包，人剩下的稀缺能力是概念性的——知识可外包，能力不能

**框定一章 · 问这几句**：
1. 章首误解现场，祛的是"记忆崇拜／天赋论／绝对真理"中至少一个吗？还是只堆知识点？
2. 核心概念有没有可检验判据？有没有失效边界？有没有反例？（判据主义三问）
3. 定义是"它做什么"（用法），还是只说了"它是什么"（词典）？
4. 章内有没有"一句冷静的话"式的边界交代——承认这章的局限？
5. 有没有落到"人"——人为什么值得掌握它，而不只是系统机制？

## 二、理念（全书相信什么）

1. 学习是建构结构，不是堆信息——知识是网络不是列表，大脑是压缩机器（学习做除法：先搭四梁八柱）
2. 概念要"拥有"不是"记住"——掌握线划在"应用"之上（布鲁姆六级）
3. 能力比知识更根本、更可迁移、更稀缺
4. 方向先于努力——杠杆第一性是方向；方向错了，其余全在放大错误。**与第 7 条同属一条乘法律的两个归零项**（这条式子是乘号不是加号：方向管往哪使劲，表征管拿的是不是那个东西）
5. 概念是活的、可修正的——勤校准是正常纠偏，不是失败
6. **能力分四级（深度轴）**——每级按作业对象命名：表征（术语表）⊃ 图式（可识别的结构）⊃ 心智模型（会推演）⊃ 解释框架（能判断什么值得相信）；概念工具建的是**第一级到第二级**，**答全四问是入场，不是到顶**（§1.4.3，2026-09-21 补；2026-09-26 正名为"能力四级"——四级的判据本就是能力动词：能提取／能认出／能推演／能判断；同日"地图"退出第1章）
7. **表征第一性（价值律：1 和 0）**——**表征是 1，图式／心智模型／解释框架是 0：1 定成立，0 定量级**。第一级决定"成不成立"（词指错了东西，上面三级再漂亮也是零），上面三级决定"能做多大事"（每加一级翻着倍往上涨）；所以第一级最便宜，也最不能省（§1.4.3，2026-09-26 补）

**框定一章 · 问这几句**：
1. 这章是把知识当"结构／网络"讲，还是当"清单／事实"堆？
2. 核心概念推到"拥有"（会用、能迁移）还是停在"见过"（记得、会背）？
3. 章末落点是"能力／可迁移"，还是只收了"知识点"？
4. 有没有体现"方向／判断先于执行"（而不是只讲步骤）？
5. 有没有体现概念可修正（勤校准），还是把概念当死规矩？
6. 本章在帮读者建**第几级**？（表征／图式／心智模型／解释框架——§1.4.3）章末清点块有没有逐级点名"本章交付了什么"？
7. 有没有把"表征"当成可以省的一步？（先建图式、再补表征＝把 0 建在 0 上；凡在本章说准的词，都要能答四问）

## 三、思路（每章怎么组织论证）

- 从误解现场出发（问题先行，不是理论先行）——且问句要是从业者真会被卡住的"真困惑"，判据翻译垫后
- 论证沿"为什么 → 靠什么 → 怎么练 → 怎么检验 → 怎么用"推进（"是什么"由规则1先立枢纽覆盖；"怎么用"可由现场演示 / 落实践 / 跨章兑现承担，不必是独立部分）
- 每一环落到可检验判据
- 既立又破：给证据同时给边界（如第1章"一句冷静的话"）、给工具同时给限定（如杠杆三限定）
- 处处用反事实检验（识别枢纽、检验概念、跨域迁移）
- 用自己示范自己：写"识别枢纽"的章自己先立枢纽；教"四问"的章自己就是四问的示范
- 先内涵、后子概念：概念含子概念时，先讲父概念的内涵（子概念作为其中一个内容），再解释子概念的内涵——不在父概念里展开子概念

**框定一章 · 问这几句**：
1. 章首是不是从误解现场出发，而不是从定义出发？（问题先行）
2. 论证是否沿"为什么 → 靠什么 → 怎么练 → 怎么检验 → 怎么用"推进？"是什么"靠规则1立住、"怎么用"靠现场演示/落实践/跨章承担——缺了哪一环？
3. 每一环有没有落到可检验判据？
4. 有没有既立又破——给证据同时给边界、给工具同时给限定？
5. 有没有用反事实检验（如"去掉它，领域还成立吗"）？
6. 有没有"用自己示范自己"？
7. 概念含子概念时，先讲父概念内涵了吗（子概念只作为一项列出）？有没有在父概念里直接展开子概念？

## 四、方法（每章该带的工具）

| 工具 | 用途 | 每章落点 |
|------|------|---------|

| 概念体系能力四构件（识别枢纽×织关系×迁移×辨边界；简称"概念能力"；子能力=根概念能力·方向盘：先抓承重柱，再展骨架） | 概念体系能力的结构 | 概念间织关系，不只孤立定义 |

| 九格（目） | 作者/审稿人查全 | 薄格可省，不可跳过 |
| 五环模型（立枢纽→织关系→逼输出→勤校准→落实践） | 训练流水线 | 判据/自查/练习考"应用"不考"记忆"；案例落实践 |

| **坐标系**（位次轴 × 深度轴·能力四级 ＋ 价值律「1 和 0」；§1.4.4，2026-09-26 补） | 给全书工具**定位与权重**——位次轴（一般 ⊃ 核心 ⊃ 根）量"先抓哪个词"，深度轴·能力四级（每级按作业对象命名：表征 ⊃ 图式 ⊃ 心智模型 ⊃ 解释框架）量"同一种能力练到第几级"，两轴正交；表征是 1、上面三级是 0；四问／识别枢纽记在第一级，**不负责"拿主意"**；上两级由 ch10～12、ch17～18 承担 | 每章可自问"本章在帮读者练到第几级"；**章末须按四级逐级清点**（框架 §五 第 12 条），"见过→拥有"点明当前层级 |

**框定一章 · 问这几句**：
1. 概念档案卡答全四问了吗？尤其"从哪来"（溯源）——最容易缺的一问？（定义链卡只要求钉定义+判据）
2. 判据/自查/练习考的是"会用"还是"记得"？
3. 案例承载概念了吗（落实践）？双线镜照在不在？
4. 九格薄格可省但没跳过吧？

## 六、重构方法：把一章改造成能力导向骨架

> 前五节的"框定问句/检查问句"告诉你**审一章**；本节告诉你**重构一章**——把底子弱、结构未对齐的章，从"现状"改造成"能力导向骨架"。设计驱动，不迁就现状。第10章（架构）按此重构为试点，其余章同法。

### 五步流程

| 步 | 动作 | 产出 |
|---|---|---|
| ① | 定这章的活 | 认知链位置（承谁/启谁）+ 反直觉命题 + 核心档案 + 案例任务（主/镜/触发点/方法底座时刻） |
| ② | 从能力导向推导理想骨架 | 读者读完要"拥有"什么 → 章节组织成"困惑→辨清→运用→拥有"的旅程 |
| ③ | 现状降级为素材 | 现有章节只提供素材（案例/段落/卡片），不迁就它的结构 |
| ④ | 设计新骨架 | 每部分回答"这段带读者完成哪个认知动作" |
| ⑤ | 对照落地 | 素材进新骨架、重写衔接、机械校验 |

### 十条重构规则

1. **先立枢纽（骨架先行）**：「误解现场」之后，正文「**本章的骨架**」块（第1章为 `### 1.1.3`）先立本章枢纽骨架（核心概念 + 关系 + 判据 + 原则），再进细节——骨架是读者后续所有内容的挂载点。
2. **四问为纲组织主体**：主体按"是什么 → 不是什么 → 从哪来 → 往哪去"组织；四问重量天然不均时可合并（从哪来织进是什么）或拆分（往哪去拆成描述+用途），不教条；每个概念卡显式四问化（四问为纲、九格为目）。
3. **"不是什么"收拢成一条磨边界弧**：把散落在各处的"不是 X"（不是图/不是选型/不是多个）集中成连续一节——判据主义成为读者的亲身体验（概念靠正例活、靠反例定型）。
4. **溯源显眼化**：演化史/词源/诞生动机不埋进定义里，提为可见位置——概念"活"起来。
5. **案例为线，不是补充**：案例进展从"部分末尾的补充"升级为"推动每个认知动作的主线"（误解现场 → 案例推进 → 反转收束）。
6. **判据主义贯穿**：每个核心概念带可检验判据——判据既是"是什么"的辨认工具，也是"不是什么"的边界工具。
7. **方法论贯穿（与第1章接线）**：把本章演示的第1章方法显式命名（反事实检验用在系统上 / 架构是压缩=压缩学习 / 勤校准=枢纽修正），不止显影段。
8. **章末"见过→拥有"显式收束**：认知反转后点破——能答全四问才算拥有，把尺子装进读者手里。
9. **不造新事实**：素材全取自现状或 00 三份；重构 = 重排 + 重写衔接，不凭空造内容。
10. **机械校验**：段落≤150、围栏/加粗平衡、版本 v+1、章题与认知链位置不动、概念总图/判据/自查/练习与新结构联动。

### 布局逻辑审查规则（六条）

> 与十条重构规则互补：十条管"怎么造骨架"（设计驱动），这六条管"审已有骨架"——审一章的内容布局，问的不是"章节顺序对不对"，而是"每部分带读者完成哪个认知动作"。源起：ch4 审查发现"验证≠确认"在 4.2.5 提前完整展开、第二幕磨边界弧变补丁，蒸馏成六条；判别力已验证——ch2（范本）六条全过、ch4（反例）触发四条。

1. **认知旅程驱动**——一章按"勾住（误解现场）→ 立枢纽（骨架）→ 建立实感（是什么）→ 磨边界（不是什么）→ 运用（往哪去）→ 拥有（收束）"排布；每部分只承载一个认知动作，不按知识分类平铺概念。**检查**：给每节标一个认知动作——有没有一节标不出来、或一节同时标两个？
2. **磨边界弧要实，不被"是什么"提前消化**——所有"不是 X"收拢成连续一节，且必须"实"：它是判据主义（方法底座时刻）的主舞台，篇幅与质感要足；辨析/边界类内容不得在"是什么"幕就完整讲完，把磨边界弧留成增量。**检查**：磨边界弧篇幅与"是什么"幕是否失衡？有没有"辨析/边界"在定义节就讲透、磨边界弧只剩补丁？（ch4 反例**·重写前**：验证≠确认完整展开塞进 4.2.5，走廊二变补丁——该章重写后已把验证与确认整段移入 §4.3.3；ch2 范本：第一幕只立判据，手艺/方法论/机械化辨析全留第二幕）
3. **一节一个认知动作（不三合一）**——一节只做一件事：定义、边界、运用各归其位；标题里的概念数 ≈ 该节承载的动作数。**检查**：有没有一节标题含三个概念/三件事？（ch4 反例**·重写前**：4.2.5「规格与规定需求：SRS 六章、验证与确认」——现题为"规格与规定需求：一份 SRS 里有什么"）
4. **单一枢纽约束**——每章围绕一个主枢纽：章首误解现场 → 开篇枢纽 → 认知反转三点一线；方法底座时刻是"教法"、不是第二主题，不得喧宾夺主；第二主线（如有）必须在开篇显式预告、且不压过主线。**检查**：章首、开篇、反转是否围绕同一核心判断？
5. **前向指针精确**——"在哪展开"的指针指到真正展开的节，不指到更晚的位置。**检查**：每个前向指针（"会在 X 磨开""细节见 X"）所指节号 = 实际展开位置吗？（ch4 反例**·重写前**：4.2.3 说规定需求"第二幕走廊一磨开"，实际 4.2.5 已立卡——现 L120 指针作"§4.3.3"、全章"走廊"零处）
6. **案例为线、紧贴概念**——案例进展紧跟它演示的正文（幕末），作为推动认知动作的主线；不在概念未立时提前演示、不在概念讲完很久后补案例。**检查**：每个案例进展与它演示的正文隔了几节？隔得远的，读者还记得吗？
