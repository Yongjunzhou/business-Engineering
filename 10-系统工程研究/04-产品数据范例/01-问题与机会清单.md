# 01 · 问题与机会清单

## 1 概述

这一份是产品开发这条链上的第一份产品数据，上游没有别的产品数据。下游四份都按编号从这里取。文档2 拿编号去列相关方与关切，文档3 把编号写进每条需求的「来源」列，文档6 把现状原话一字不改地摘过去，文档13 取目的陈述，写进册头的「预期目的」。「文档N」指那份清单里的第 N 份。这一版 v18，2026-11-26 定稿，按规范 v0.32 与规程 v6.34 复核。承接档是新增，没有现成的同类本子与沉淀清单可取，全由原料转出。七个阶段走完，按规范 5.1 的五条一条一条判到二十二条记录；当场改不了的三条，记在同编号过程记录第 8 条。

## 2 术语

本清单用的词，定义与出处见《01-问题与机会清单规范》2 章。这里只写本清单取值时按哪一种读法用。

**表2-1：专用术语的读法与用法**

| 专用术语 | 读法与用法 |
|---|---|
| 问题 | 一条「现在什么样」的记录；算不算一条问题，按 15288 §3.26 判。本清单立了问题1~5 |
| 机会 | 与问题并列的一类记录，写得出抓住它的条件才算；本清单立了机会1~4，写不出的作愿景不入表 |
| 抓住它的条件 | 机会行必填的一个数据项。只写已具备的外部既成事实或已到手的起点，不写行动项 |
| 两型约束 | 要求型写「须：…；判定＝…」，事实型写「是：…；现象＝…」，两型不混写；本清单 C1・C3・C4・C5 属要求型，C2 属事实型 |
| 根因两环 | 直接原因与直接原因的成因分两数据项，只在问题表；机会表不设 |
| 与目标态的差距 | 问题表那一个数据项写与目标态的差距，机会表那一个数据项写要把它做成还缺的那一样，两处不同义 |
| 综合目的 | 取目的参照各行交集的那一句，不带主语，不设指标 |
| 研制方使命 | 用承制方口吻写的一句，与综合目的并列，不占目的的行 |
