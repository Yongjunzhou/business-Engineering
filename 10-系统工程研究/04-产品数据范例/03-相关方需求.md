## 2 术语

通用词只指路到《产品数据规范编制规范》第 3 章。本份特有的词：

| 专用术语 | 定义原文 | 定义出处 |
|---|---|---|
| 端到端业务 | 文档4 生命周期树的枝梢节点：起于一份正式的需求或要求，止于该需求被正式确认得到满足；正式＝书面，平台内留痕的事件记录视为等同书面；本份以业务候选号指代 | 03 册 3.1；文档4 |
| 枝梢节点 | 树里最深一级的干枝节点，即承接落点；上一份的叶节点落进它，一条叶落一个枝梢，多条叶可落同一枝梢。文档4 的枝梢节点是端到端业务，文档5 的枝梢节点是一个被度对象乘一项质量特性 | 03 册 3.1；文档4、文档5 |
| 叶节点 | 树的最末那一层、可独立验证的条目；上一份的叶节点就是下一份的需求，本份的五十五条即本份的叶 | 03 册 3.1 |
| 承接单位 | 指代一个枝梢节点的那一对值：功能性行取主角色与触发事件，定文档4 的枝梢节点即端到端业务；非功能行取被度对象与质量特性，定文档5 的枝梢节点；一条需求只落一个枝梢节点 | 03 册 3.1 |
| 业务候选号 | B 加两位数字，从 B01 起，本份二十三行 | 03 册 3.1 |
| 节点候选号 | J 加两位数字，从 J01 起，本份二十九行 | 03 册 3.1 |
| 关切对账 | 一条关切与承接它的需求之间的对账，一行一条关切 | 03 册 3.2.3 |
| 容易度量 | 易实现性需求指标里体现「更容易」的那个量 | 03 册 3.2.1 |
| 数据项 | 表里一个可填值的位置，即某一行与某一列相交那一处；本份正文的取值都装在这里 | 03 册 3.2 |
| 访谈条号 | 《访谈走访记录》B-2 各条，写齐被访岗位、时点、访谈三问与原话 | 本份 4.1 |
