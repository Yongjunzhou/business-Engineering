优化 20 号报告（及各研究报告）时，**不要把教材书侧联动列为挂账或下一步建议**——ch6 同步、训侧重派生、成书 build 由用户自行考虑和统筹（2026-09-02 用户定："你不要考虑教材书，这个我会考虑的"）。

**Why**：教材书与研究报告是两条线，用户自己掌握教材书侧的联动时机与方式；AI 在报告批次收口时反复列出教材书挂账，超出用户需要的管理粒度。

**How to apply**：报告批次收口汇报只涉及报告本身的状态与后续报告侧可做的事；教材书侧联动仅在用户明确指令时执行。相关：[[work-scope-50-only]]
