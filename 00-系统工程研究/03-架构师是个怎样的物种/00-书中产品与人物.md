# 书中产品与人物

---

书里有两支虚构的团队：一个造有形的设备，一个造无形的系统。同一个词，在他们两家各长一个样——这是这本书想证明的第一件事。

#### 冰链科技：造温控箱的那一家

冰链造医疗冷链运输温控箱。产品 M3 把硬件、嵌入式、云端和 App 联在一只箱子上：疫苗与药品从冷库到接种点，箱温守在 -20℃~8℃，全程留得下温度记录；断链 30 秒内告警，断电保温 72 小时。这本书用它演示造有形设备的那一路。

| 姓名 | 岗位 | 在书里管哪一摊 |
|---|---|---|
| 林涛 | 产品经理 | 需求、评审、对客户 |
| 赵刚 | 产品开发经理 | 产品开发全局、评审签字 |
| 石军 | 嵌入式硬件工程师 | 温控硬件、固件 |
| 吴浩 | 云端软件 | 数据采集、App、追溯平台 |
| 季昭 | 测试 | 验证与确认 |
| 小张（女） | 系统工程师 | 整条链受控与可追溯 |
| 小周 | 制造与供应链 | 量产、物料、批次 |

#### 恒信集团：做审批系统的那一家

恒信做跨部门的合同审批系统。法务、财务、业务三家在同一份合同上签字，一套流程管住合同版本与台账：月底对账要在两小时内对得平、一笔不差，合同数据留档十年。这本书用它演示造无形系统的那一路。
