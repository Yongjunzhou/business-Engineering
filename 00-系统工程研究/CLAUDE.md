# CLAUDE.md（00-系统工程研究 · 系统工程研究项目）

本目录是 AOS 项目集里的**系统工程研究项目**——研究报告（`00-系统工程相关研究报告/`）→ 两个产出：**教材书**（`03-架构师是个怎样的物种/`）+ **培训教材**（`02-架构工程师培训材料/`）。

## 项目边界（项目集内 · 操作互不干扰）

本项目是 AOS 项目集的一员，各项目共同指向「**把不同专业的工作或事项工程化**」这一目标；本项目负责该目标在 **系统工程方法论 → 教材**上的展开。**自包含在本目录内**（AOS 根 CLAUDE.md §九）：

- **处理教材**：工作目录 = 本目录（`00-系统工程研究/`），读本文件 + `claude-memory/`。
- **处理 AOS 主线工程**：工作目录 = 仓库根，读 AOS 根 CLAUDE.md + 主记忆 `.claude/memory/`——**不擅自改动其内容**，除非明确要求。
- **主题上可互引、操作上自包含**：本目录的方法与结论可被其他项目引用，反之亦然；改动落在谁家由谁做。

## 记忆隔离协议（必须遵守）

本项目的记忆**独立存放**，与 AOS 项目根记忆（`.claude/memory/`）**互不干扰**：

- 本项目的记忆位于 [`claude-memory/`](claude-memory/)：`claude-memory/MEMORY.md`（索引）+ `claude-memory/教材项目.md`（主记忆）。
- **编写/打磨教材时**：先读 `claude-memory/MEMORY.md` 与相关记忆文件，写入 `claude-memory/` 目录。
- **禁止**把教材内容写入 AOS 根 `.claude/memory/`（auto-memory 即此目录，见 AOS 根 CLAUDE.md §八）。AOS 根 MEMORY.md 只保留一行指向本目录的指针。
- 每个教材会话结束时，把最新状态同步回 `claude-memory/`；跨设备共享走 git（机制见 AOS 根 CLAUDE.md）。

## 提交边界（单仓库 + 约定分区）

仓库是 AOS 单一 git 仓库，本项目不建独立 git。提交时按目录语义分区：

- 教材改动与 AOS 主线改动**分别 commit**（commit message 注明归属）。
- 处理教材时，不把 AOS 主线改动混入本次提交；处理 AOS 主线时，不把教材改动混入（除非明确要求）。

## 工作风格

- **禁止选项式交互**：讨论/确认事项时一律自由散文陈述（背景 + 问题 + 建议 + 理由），不用 AskUserQuestion 选项卡片让用户做多选题；用户自由回答"改/不改/怎么改"（2026-08-25 用户定，详见 `claude-memory/feedback-no-option-interaction.md`）。
- **英文引用须中英并列**：凡涉英文（逐字引文、术语、缩写、方法名、题名、探针词）一律同时给出英文与中文，逐字引文紧随「（中译：…）」；**不允许**同段末尾或表下"中译各条依次为…"式的后置集中翻译。**交谈答复与全部产出文件（研究报告／教材书／培训教材）同此**（2026-10-13 用户定，详见 `claude-memory/feedback-英文引用须中英并列.md`）。
- **报告库出件的连带随章落实（不另开批）**：某号研究报告判有连带后，**不立"批"、不提前预改**——把影响写成**随章取料单**（`claude-memory/pending-align-textbook-to-NN.md` §五「随哪一章」表），**随该章重写时一并落**；**执行点＝该章入口文件 §〇 开工单里的"★ NN 号随章影响"一行**（人只发 `开工第N章`，agent 自读即见）。连带件（框架 §三／目录／案例圣经／`19-附录.md`／主线 §三／三条线索／训侧对应单元／派生件与 `成书/build`）**与该章同批**（2026-10-13 用户令，详见 `claude-memory/feedback-报告连带随章落实.md`）。
