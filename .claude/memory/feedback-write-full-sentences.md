人类 2026-09-22 定，已立为 [00-doc-conventions §8.8](../../../00-generalspec/00-doc-conventions.md#88-句子与段落可读性) 的规则（v2.13 立两条，v2.14 扩第三条）。

**人类原话**：AI 写「人类在轮内介入三处：」，人类改成「**在本任务处理过程中，有三个步骤需要人类介入。**」——"这样的表达多好理解，你整篇都是'人类在轮内介入三处'这个味道，太不好了"；随后"你把这个作为规则吧，**我们被你虐的太可怜了**"。

**Why:** 压缩体是索引体、幻灯片体，不是给人读的散文。读者要自己补出主语、谓语、中心词才能读懂，补出来的还未必是作者的原意——**省下的字，全部转嫁成读者的解码成本**。判据一句话：**读者需不需要自己补词？需要，就是没写完。**

**How to apply:**
- 正文一律写完整主谓句。五处最容易省，逐条自查：主语与谓语齐不齐 / 数词后有没有中心词（"三处"→"三个步骤"）/ 有没有自造压缩词（"轮内"→"在本任务处理过程中"）/ 动词有没有被名词化（"边界取…处"→"边界取在…之处"）/ **关系有没有压进定语链**（"本任务是业务系统设计这一段第一个需求-方案对里产品视角这一半"→"本任务落在业务系统设计这一段第一个需求-方案对上，占其中的产品视角这一半"——**别只留一个"是"顶着长定语，用动词把关系依次说开**）。
- 层次、并列、对应、取值这类**关系信息进列表或表格**，散文只写说明与理由。判据：这句话能不能画成一张表——能，就不写成句子。
- 例外：**术语是命名，可以压缩**（末三级、岗位级E2E业务），且必须前后一致；**句法压缩不行**。两者别混。
- 套话与标题式引子（"XX：""XX——"）不算句式豁免；引子后面接的内容仍须是完整句子。
- 存量文档同病的一大片——改一处时顺手看邻居与同章，别只改被点名的那一句。
- **简称与比喻词首现先给实体**（2026-09-22 第三条，人类：「第一个字"叶"就把人给搞懵了，叶是啥？」）。缩写、简称、树上的比喻词（叶／干枝／枝梢／形态／截面），首次出现时与实体并写；**尤其别把还没露面的词放在句首**。老规则只管到"缩写标全称"一格，管不到比喻词——**跟 §8.1 缺"位置与关系"那一格是同一个病灶：规则表的格子不全，那一类就没人管，写的人自然顺手写坏。**
