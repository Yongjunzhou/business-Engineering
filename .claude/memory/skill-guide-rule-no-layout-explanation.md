**2026-09-21 定，落 93 第 75 版**（提交 `61a69018`，两仓已推）。

## 第十一条原文要点

正文只给规则本身，不给规则的编排。**三不写**——**不汇总**若干节合起来的样子（「哪几步并非每轮都走」「本任务的检验共三处」）；**不作比较**（「并非」「不再」「才是」「都在这段对话里完成」）；**不作安置的理由**（「所以只能自上而下逐级走」「所以它排在长干枝之后」）。各步何时走、检验落在哪几处，就地写在它们所属的那一节；步与节的先后由步序与总览表承载。

**判据**：删掉这句话，执行者照章办事会不会做错——不会，它只是在讲编排。
**归因**：带这套味道的句子多半是后加的——作者改动了编排，就顺口讲给读者听；这句对第一次读的人是噪声，对读过旧版的人才是信息。
**同族**：第二条管文件自身的结构，第十一条管任务自身的编排。

## 同轮改掉的生成源（关键）

93 §3.5 原条要求引题"只写**表上看不出来的整章级事实**——一次运行从哪起、收于哪，**哪几步并非每轮都走**，本任务的检验分布在哪几处"。**人类举的那段病句，连"并非每轮都走"都是这条规范的原词**——照规范写就必然长出那段。故同轮改成：引题只写一次运行的起止；各步何时走、检验落在哪几处，就地写在各自那一节。

**方法要义**：实例改完，**规则源必须同轮改**，否则下一轮照规范又长回来。

## 连带

- §2.4 第一条补「**分工声明不算引用**」——「按 X 执行」「以 X 为准」「X 单源为」「本任务在此写它这一侧的特化」都是"本文档与另一本文档怎么分工"，读者要的答案这里没有；点名「**固定机制按 X 执行**」为最坏的一种（连规则名都不给）。
- §3.5 禁含由「复述协议」扩为「复述**与转引**」，明写"写一句「按 91 附录A 执行」同样禁止"。
- abr 同步删：第五章引题整段、§4.2.1 与 §4.2.2 的安置理由、§4.2.3 的"不必逐个判"、12 处对外转引；长句按"一句一个主语"断开 14 处。
