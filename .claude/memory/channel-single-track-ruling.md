**人类 2026-09-20 定**：人类对 AI 产出的方案给反馈，通道**只有对话一条**，全链一致。原 [91 §A.5](../../20-pl4eos/10-pl4eos-subpl-sysdev/10-wfsysdev-4-eos/91-eos-biz-eng-spec.md) 的「线下文档修订」轨——人类在 `确认状态` 字段标注 `[同意]`/`[修改]`/`[驳回]`、或自由文本编辑方案内容，经 git diff 检出——**退役**。这是把 2026-08-19 的「反馈双轨化」（那次是 wft01/02/03 链级统一到双轨，91 §A.5 随之 v5.20）**翻回来**，翻转本身已经人类确认。

**Why**：确认动作搬进了轮内（一轮从选料走到入库），就没有事后标注的位置。双轨存在的理由是"人类可能不在会话里"，新序假定人类就在会话里。判据：**这条通道承载的是"确认"还是"回流"**——确认（人类对 AI 方案表态）可以在会话里一次做完；or02 那种"持问题清单线下向相关方澄清"是**回流**，性质不同（但仍已人类裁定一并退役，见下）。

**91 已落（v5.64，提交 `5a1d1775`）**：
