2026-08-21 人类要求"eng 与 biz 一致，非主价值链以 biz 链为标准"，三链（biz×3 + eng×4 + nfr×2 = 9 人类方案 + 9 SKILL）的非主价值链 Step 框架统一为 biz 形态：

**统一内容**（主价值链设计步一律不动）：
- **三角色分工 → 全链移除**：eng/nfr 的"三角色分工表"（流水线开发者/AI/EOS 开发者）删除，角色信息并入 §一 职责定位 + Step End 方案反馈锚点；EOS 开发者"可用性确认"维度保留为锚点内容不丢失
- **Step End 双区 → 单区**：eng/nfr 的"设计审核 + 可用性确认"合并为"一、方案反馈"，审核/可用性锚点保留为 bullet；biz 本就单区
- **Step 2 处理表 → 内联 5 行**：全链统一"显式修改指令/质疑讨论/整体确认/模糊意见/线下修订检出"内联表；整体确认统一追 `[同意] [已处理]`；biz 补缺行/缺表（wft01 4→5行、wft02/03 补表）
- **输入校验表 → biz「判定|动作」格式**：eng/nfr 的「判定|类型」列向 biz 靠拢（硬退出/软提示并入判定列括号标注）；注意反向也曾误改（biz 曾被我改成 eng 格式，已还原）
- **布局表 → 7 列统一**：wft03-biz 去掉独立「§7.3 任务」列（Task 编号并入职责列）
- **标注纪律框架**：§二 补统一"标注纪律"（`[推断]`/`[待下游推断]`/`供人类确认` 三类框架全链一致，各链按域标注自己的标记——biz 高密度如 `[待wft02推断]`/`[推断-待OR确认]`/`[需裁决]`，eng/nfr 轻量）
- **反馈总结补齐**：wft02-biz/wft03-biz 补 §5.3.3

**版本号**：wft01-biz v3.15 / wft02-biz v9.1 / wft03-biz v9.5 / wft01-eng v9.4 / wft02-eng v9.9 / wft03-eng v8.1 / wft05-eng v9.1 / wft01-nfr v5.6 / wft04-nfr v5.6（各 SKILL 同步升版）。

**反转了早期裁决**：eng/nfr 的三角色四区是 v8.8/v8.0/v5.5 等版本人类裁决"保持"的，本次按"以 biz 为标准"方向反转。后续不要再引入三角色分工表/Step End 双区。
