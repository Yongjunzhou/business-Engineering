## 〇、v1.23 定形的形状（2026-09-16）

```
Rn：角色履职业务 → 业务域① → 相关方角色② → 角色职责③ → E2E职责④
        → 业务文档⑤（业务输出的产品数据，对应本文档开发任务）
            → 任务节点⑥（文档开发任务的多个步骤，**枝梢**）
                → 用例场景⑦（**叶**）

Pn：输出产品业务 → 业务域① → 产品类型② → 产品构件类型③ → 构件开发WBS（包）④
        → 业务文档⑤ → 任务节点⑥（枝梢）→ 用例场景⑦（叶）

R0：角色履职业务 → 业务域①（流程与IT，单域） → 相关方角色② → E2E职责③
        → 业务文档④ → 任务节点⑤ → 用例场景⑥          〔相对 Rn 少「角色职责」一级〕

P0：输出产品业务 → 业务域① → 产品类型② → 构件③（引擎） → 配置单元④（CU） → 配置信息组⑤（末级，无叶）
```
