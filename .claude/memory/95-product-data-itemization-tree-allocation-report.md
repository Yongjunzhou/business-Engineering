**v0.5 删节理由（可复用判据）**：原 §3.5「叶从何而来：属加种差」被删，因**不承担论证功能**且与本报告目的不一致——① 归属错位（叶是 §二条目化的产物，§4.5 已言"原子就是叶"）；② 判据冲突（属加种差给的是**概念可定义性**判据，报告实际用**可验证性/可分配性**）；③ 层级性质未辨（波菲利之树是 **is-a 分类**，报告的树是**整体—部分分解**）。处理：§3.3 补"树必有终止级 + **在哪一级停是判断不是数学结论**"；§3.4 条件二补 **分类 vs 分解** 之辨；§4.5 改引 §3.3 直接陈述判据。**通用判据：一条引用若删掉后上下游都不缺东西，它就不是论据，是装饰。**

**三问结论与依据**：
- **条目化** ← ISO/IEC/IEEE 29148 良构需求特性（**Singular** / Unambiguous / Verifiable …九条）；分"单条需求"与"需求集"两层。
- **树形化**（v0.2 补第二层）← 第一层"为什么分层"：Simon《The Architecture of Complexity》(1962) 层级与近可分解性 + WBS **100% 规则**（MIL-HDBK-881/MIL-STD-881）+ MECE + INCOSE **规格树**；**第二层"条目能否组装成树"**：树序 ⇔ 递归划分（故"能组树"平凡成立，真问题在判据）＋ 波菲利之树（属加种差；**叶 = 按同一判据分不下去的那一级**）＋ **Bliss 分类法"division must be by one principle only at a time"**（同层混用判据 → 交叉分类 → 不再是树；分面分类是对"树不够用"的正式承认）＋ 单继承 vs 多层级（多归属只能得 **DAG**）＋ 层次聚类/FCA（FCA 得概念格，非树）。**成树三条件 = 分组判据单维 + 条目单归属 + 分组完备互斥**；另区分**自顶向下分解**（判据=设计意图，须可辩护）vs **自底向上聚类**（判据=相似度，须可计算）——设计链属前者，"条目不是原料，是挂点"。
- **向后分配**（v0.3 补第二层）← 第一层"为什么发生"：ISO/IEC/IEEE 15288 技术过程链（Stakeholder Needs → System Requirements → Architecture → Design，输出统称 requirements）+ SEBoK「logical architecture … from which more detailed system requirements can be derived」+**公理化设计 Suh**：`{FR}=[A]{DP}`、独立性公理、**zigzag 分解** + Gotel & Finkelstein 追溯性定义。**第二层"为什么是这个形状"（叶 → 唯一枝梢、N:1）**：4.4 设计＝域间映射，落地形式就是 allocation（15288「requirements are allocated to system elements」+ SysML Allocation）；4.5 定义域＝前序的叶（29148 Singular/Verifiable ⇒ 只有原子条目可被分配）；**4.6 值域＝后续的唯一枝梢——"叶→枝梢"不是跨级，而是两侧"各自最深可用原子"的对齐**（需求侧完整态已出、方案侧只到框架；方案叶来自该枝梢往下的分解，不是上游输入）；**4.7 基数＝允 N:1、禁 1:N，两者理由不同源**——N:1 ← Parnas 信息隐藏/模块内聚；1:N 禁止 ← 变更传播+重复实现+AD 耦合；**不对称：AD 里 N:1 与 1:N 同为耦合**，故判据是"需求侧独立 + 方案侧内聚"的工程平衡。

**边界（别读成"万物皆可干净条目化"）**：耦合设计普遍存在（AD 自己承认）；需求集的 Complete 不可形式化证明；**"能否条目化"是判据而非断言**——判据＝能否被独立解释、独立验证、唯一交出去；切不动走三出口（合并／降级为约束／显式标注耦合）。

**对本项目的意味（§六，应用推论）**：条目化↔"叶只在完整态产出"；树形化↔"框架态（根→枝梢）/完整态（根→叶）"；向后分配↔"上一份叶→下一份枝梢"。**四条结论已落 94 v1.5**（人类定 2026-09-10）：① 94 新增 **§1.2 树的成立条件**（判据单维/条目单归属/完备互斥）；② 94 §1.3 补**叶的判据**（可独立解释/验证/唯一交出去；终止标准引通用规范 §2.2.2）；③ 94 §1.4 补**承接三条依据**（含**基数两侧理由不同源**）；④ 94 §1.4 补**反误读注**（"叶→枝梢"非层级换算）。93 → v0.10 节号联动；91 无同源表述，无需改。
