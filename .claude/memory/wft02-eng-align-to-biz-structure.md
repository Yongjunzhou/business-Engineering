**人类定义：设计 = 分解、分配、分析**（不含框架定义、不含详细定义）。

**推理链（人类逐步确认）**：
1. 设计的对象与动作：**引擎需求框架末级节点（=名称级 CU 候选）** → 分解 → **详细定义的需求条目** → 分配 → **找一个 CU 承接**（1:1）
2. 分解 = 框架末级节点 → 详细需求条目；分配 = 详细需求条目 → 找 CU 承接；分析 = 检查分解分配正确性

4. **收敛判定 ⊂ 分配**——"找一个 CU 承接"本身就是复用/新建/拆分/合并的决策（对应七判定）
5. **∴ 设计（分解分配分析）应在 wft01-eng**（含收敛判定上移）；**wft02-eng 退为详细定义**（配置信息组/配置能力/依赖/状态迁移）
