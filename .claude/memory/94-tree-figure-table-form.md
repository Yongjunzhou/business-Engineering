**人类 2026-09-21 定**：94 号文档里各产品数据树的**说明外移成表，与图分离**——图只留「节点名 ──── 圈号」，紧跟图下给一张「级｜节点｜意义」表。体例照 abr／abp，也合 93 §2.3「图内只写节点名称，节点意义另列成表」。

## 落成三件

- **十棵树转「图＋表」**：文本化原始需求／相关方功能需求／相关方非功能需求／Rn／Pn／R0／P0／SR-F／SR-N／平台构成。原来的变长横线（为对齐"名→说明"）随之改成固定四横——对齐服务的对象没了。
- **全部图表加编号与标题**：**图2-1~图2-10**、**表1-1~表1-6**、**表2-1~表2-11**。编号按**文档出现次序**，不按节号（§2.0.2 那张拿的是图2-1）。
- **同一级只在首次出现处详述**，后续写「**见 表X-Y**」（19 处）；**各树独有的尾巴保留**——R／P／R0 树各自的"在 X 树上是枝梢节点／叶节点"、Rn ⑤ 的正式／轻量判据与计划说明。
