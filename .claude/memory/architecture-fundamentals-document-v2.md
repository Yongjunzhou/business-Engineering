**术语口径**：设计链层缩写为 **BP**（业务流程）；4A 域使用 **BA**（业务架构）。ISO 术语：requirement→需求、need→需要、expectation→期望、specified requirement→规定需求、review→评审、verification→验证、validation→确认。

**Why**: 从「概念是什么、工程是什么」出发，推至架构决策的不可逆性、视图完备性推导、质量把关（评审/验证/确认）、变与不变的治理（配置/基线/变更）。
