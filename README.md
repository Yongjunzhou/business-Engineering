# AOS · 业务工程化项目集

## 项目定位

AOS 是一个**业务工程化项目集**：为各类业务建立基于 AI 的流水线，后续按流水线开展业务。仓库顶层每个编号目录是一个独立项目，各自自包含（项目 `CLAUDE.md` + `claude-memory/`）。

**主线工程**（`10-eos-engineering/`）是这套方法最系统的一次展开，包含三个产品：

- **元流水线**：用于设计 EOS 流水线的流水线。采用通用方法论对自身进行系统设计，产出 EOS 流水线的完整架构定义。自身按四阶段开发：系统设计（已完成）、构件开发（待扩展）、集成交付（待扩展）、系统运维（待扩展）。开发空间 `10-eos-engineering/10-pl4pleos/`。
- **EOS 流水线**：服务于 EOS 全生命周期的流水线，由设计线（系统设计）、开发线（组件开发）、集成线（集成交付）、运维线（系统运维）四个子流水线组成。当前设计线已完成，其余待开发。构件位于 `10-eos-engineering/20-pl4eos/10-pl4eos-subpd-sysdev/`。
- **EOS（企业运营体系）**：被构建和运维的目标系统——IT/AI 化的企业运营系统，覆盖市场、研发、生产、售后和管理等业务。开发空间 `10-eos-engineering/20-pl4eos/`，产品本体 `10-eos-engineering/30-eos/`。

第四个并行目标是：通过三个产品的实践，探索和验证复杂产品开发方法论，沉淀通用经验至 `10-eos-engineering/00-generalspec/`，含准则、模板、术语和实例。

**独立项目**是同一工程化目标在其他专业领域上的展开：

| 项目 | 位置 | 说明 |
|------|------|------|
| 系统工程研究 | `00-系统工程研究/` | 系统工程方法论 → 研究报告、培训教材、教材书 |
| AI 部署研究 | `01-AI部署研究/` | 企业私域大模型推理平台选型与建设方案 |
| 健康研究报告 | `02-健康研究报告/` | 健康主题书稿讲读摘录 |
| 现代思维工具研究 | `03-现代思维工具研究/` | 思维工具研究（激励相容） |
| 投资工程研究 | `04-投资工程研究/` | 投资工程——材料准备期 |

`_candidate-businesses/` 是**候选业务池**——尚未立项为业务工程化项目的候选业务域，不是项目。

## 方法论概览

本项目遵循**五层系统设计方法论**：

```
OR（原始需求）→ SR（相关方需求）→ BP（业务流程）→ SysReq（系统需求）→ PA（产品架构）
```

三条核心规则：**1:1 分配约束**、**N:1 承接支持**、**双向追溯**。详见[通用设计规范](10-eos-engineering/00-generalspec/01-generalspec-sysdev.md)。

主线工程包含三个产品，构成一条三层产品构造链：元流水线 → EOS 流水线 → EOS。详见 [`CLAUDE.md`](CLAUDE.md) §「三层构造链」。
