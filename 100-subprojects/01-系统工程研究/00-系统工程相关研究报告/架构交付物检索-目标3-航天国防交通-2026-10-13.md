# 架构交付物检索报告 · 目标 3：航天／国防／交通

**判定基准**：ISO/IEC/IEEE 42010:2022

- **判据 A（定义口径，§3.2）**：architecture ＝ 实体在其环境中的「基本概念或属性」（fundamental concepts or properties）＋ 管住该实体及其相关生存周期过程怎么实现、怎么演化的「管控原则」（governing principles）。关键：架构 ≠ 元素与关系的规格（后者是 ISO/IEC/IEEE 15288:2023 §3.13 名词 design / §6.4.5 设计定义过程的产物）。**只给「组件图＋接口清单」的文件按 A 判不满足**。即 A 要求文本中存在关于「基本概念/属性」与「管控原则/架构原则」的明文论述。
- **判据 B（描述口径，Clause 6 的 shall 要点）**：6.1 识别实体与其环境＋预期用途；6.2 相关方（stakeholders）；6.3 相关方视角（stakeholder perspectives）；6.4 关切（concerns）；6.5 方面（aspects）；6.6 视角（viewpoints）；6.7 视图（views）；6.8 视图件（view components）；6.9 对应关系与对应方法（correspondences / correspondence methods）；6.10 本质决策与理由（rationale / essential decisions）。**仅用 42010 的词汇 ≠ 真的具备 Clause 6 装置。**

**检索日期**：2026-09-19

## 二、目标 2：ESA / ECSS

> **前置纪律声明（对应用户「不要拿框架/规范/模板冒充某实体的 AD」）**：ECSS 是**标准体系**，其文件是**规范/模板（DRD 模板）**，**不是「某个具体实体的架构描述（AD）」**。故下列 ECSS 条目**不计作「某实体的 AD」**，只回答「该体系如何处置 architecture 与 design」，并如实给出 A/B 判定。

## 八、诚实的总体结论与缺口清单

1. **在本次可公开取证的航天／国防／交通材料中，没有一件同时满足 A 与 B。** 最接近 A 的是 **European ATM Master Plan 2025**（愿景＋五大转型杠杆＋SDO/DP，属「概念＋原则」体例）与 **NASA SCaN ADD 摘要**（含 `define a flexible architecture, update the architecture periodically, use ADPs...` 等管控性表述）；最接近 B 的是 **EATMA**，但因其正文为 PDF、本环境取不到，**只能记「不能判定」**。
2. **普遍形态判断**：政府/国际组织公开侧真正以「架构」命名的东西，绝大多数落在两类 —— **（a）结构＋接口型**（Galileo/EGNOS 页面、ECSS DDF、SCaN Integrated Network 特征项），**（b）战略/框架＋条目型**（GANP-ASBU、EATMA 仓库、SESAR Solutions、ATM Master Plan 的 SDO/DP）。**「基本概念或属性＋管控原则」型文本确实存在，但通常不在名为 architecture 的文件里**（例如概念层被外置到 GATMOC Doc 9854；ECSS 的概念层落在 System concept report 与 terminology）。
3. **ECSS 侧的关键定论（HTML 可核）**：ECSS 现行 144 项标准中**无 architecture 标准**；ECSS-E-ST-10C Rev.1 的全部 DRD 附件中**无 ADD**，对应产物是 **DDF（Design Definition File）** 与 **DJF**、**System concept report**、**Function tree**、**Specification tree** —— 即：**ECSS 走的是「设计定义（15288 式）」路线，而非「架构描述（42010 式）」路线**。
4. **本环境限制导致的未取到（诚实列出，供后续换环境补证）**：
   - 所有 PDF（NTRS 全部、EGNOS SDD、EATMA factsheet/SESAR 交付物、GANP 战略件、FAA roadmaps）—— 本环境 web_fetch 不支持 `application/pdf`，只能给链接＋搜索片段；
   - `ntrs.nasa.gov` 全站 403；`icao.int` 主站 403；`collections.si.edu` 403；`en.wikipedia.org` 被解析为非公网 IP；NASA 旧链接 `nasa.gov/pdf/140649main_ESAS_final_report.pdf` 实测 404。
5. **优先补证清单（按价值排序）**：
   1. **EATMA Guidance / EATMA 架构描述**（判断 B 的最强候选）；
   2. **Galileo Mission High Level Definition (HLD)**；
   3. **ICAO GATMOC (Doc 9854)** 与 **GANP 第八版战略件**（ASBU 的概念层）；
   4. **SCaN ADD 正文 Vol.1 / Vol.2**（验证 A 的「部分」是否升至「满足」）；
   5. **DRA 5.0 与 ESAS 正文**（把「不能判定」落地）；
   6. **FAA NAS EA 的 Data and Information Management Integrated Views** 与 **FAA Services Hierarchy**（看是否真有 view / concern 定义）。
   补充候选：SESAR 2020 交付物 `documentIds=080166e5e85ce4d5` / `080166e5c8c63150` / `080166e5d956945e`（三份含 EATMA 与 Master Plan 架构演化的 PDF）。
6. **纪律执行声明**：未凑数；未把框架／规范／模板冒充某实体的 AD（ECSS 各标准已明确标注「规范类，不计作某实体的 AD」）；无原文证据处一律写「不能判定」而非「符合」；所有英文引句来自实际读到的 HTML 或标注为「搜索摘要」；未引用本机项目内部文件。
