## 第 1 步 · 剖章立骨

**这一章回答的问题**：为什么同一个词在每个人嘴里指向不同的东西？误解有哪三种形态？用哪把九格尺子能钉死概念？这本书按什么认知链组织？

### 核心概念（一句话定义）
1. **术语（term）**——能指、那个标签/名字；"名牌"
2. **概念（concept）**——所指、标签背后的本质；"名牌背后的人"
3. **事物本身**——指称、实际存在的那东西
4. **能指 / 所指**（索绪尔）——符号的形式（声音/文字） vs 符号的内容（概念/心理印象）；二者靠**约定**相连
5. **涵义 / 指称**（弗雷格）——呈现对象的方式 vs 实际指向的对象；**涵义 ≠ 指称**
6. **语言 / 言语（langue / parole）**——社会共有的规则系统 vs 具体某人的某一次使用
7. **同物异名**——同一指称、多个涵义（= 漏的根源）
8. **同名异物**——同一符号、多个所指（= 吵的根源）
9. **术语漂移**——一次次的行业借用叠出多个所指；词汇跟着行业走
10. **词汇病三形态**——病一 说不出定义只能举例 / 病二 同词异义各指各的 / 病三 翻译伪朋友
11. **概念档案（九格）**——定界（定义①/对立⑥/辨析⑦/英文⑨）·溯源（背景②/历史③）·致用（问题④/场景⑤）·纠误（误区⑧）
12. **判据**——让定义从"一句话"变成"一把尺"的可检验标准

### 对立概念（远界）
- 术语（能指）↔ 概念（所指）↔ 事物（指称）——三分层，不是两两对立而是三层各归其位
- 例子 ↔ 定义（病一：插图 vs 判据）
- 平时不爆 ↔ 关键时刻爆（病二的时间维度）
- 中文（意合、词根不可见）↔ 英文（词根可见、原词现形）（病三）
- 等级 ↔ 质量（辨析格示例：高档车可以是差质量，低档车可以是好质量）
- 架构 ↔ 架构描述（辨析格示例：描述会过时，基本概念持续起作用）
- **语言灵活 ↔ 概念对齐**（全章贯穿的真悖论，两端皆成立）
- 漂移（无害）↔ 不对齐（可怕）

### 关联概念（近界辨析）
- 术语 × 概念 × 事物本身（弗雷格三列对位表）
- 同物异名 × 同名异物（两种"概念争议"游戏；一个漏的根源、一个吵的根源）
- 晨星 × 暮星（涵义不同、指称相同）
- 漂移 × 言语（每次漂移始于某个人的某一次 parole）
- 钉死定义 × 语言演化（不是反对演化，是反对同一场会议里三个版本演化）
- 语境 × 所指（一词多概念靠语境定）
- 评审 × 验证 × 确认（翻译伪朋友，第7章主角）
- 认知链（第1章发尺子 → 第14章整合）

### 核心原理（机制，为什么）
- **P1 符号=能指+所指，关系是约定**：语言不是精确编码系统，而是一套约定；约定是历史积累，不是逻辑推导。语言的模糊不是 bug 是 feature——灵活的另一面就是歧义。
- **P2 能指任意、所指实质**：能指和所指不一一绑定，"苹果"叫成 banana 你想到的还是那种水果；能指是任意的，所指才是实质。
- **P3 涵义 ≠ 指称**（弗雷格核心贡献）：同一个指称可以有多种涵义，同一种涵义也可以被多个符号表达。
- **P4 术语会漂移、漂移始于言语**：语言规则是全社会慢慢变的，而每一次漂移都始于某个人的某一次言语——有人用了，别人跟着用，用得多了，语言就多了一个所指。
- **P5 漂移无害、不对齐才可怕**：钉死定义不是反对语言演化，是反对在同一个会议里用三个版本演化。
- **P6 两种概念争议游戏**：同物异名是漏的根源（你以为在谈两件事、其实在谈同一件 → 重复建设）；同名异物是吵的根源（你以为在谈同一件事、其实在谈三件 → 四十分钟吵架）。
- **P7 例子不是定义**：定义回答"它是什么"，例子只回答"它长这样"；定义要带可检验的判据。说得出口的例子往往让人误以为自己懂了。
- **P8 病二平时不爆、关键时刻爆**：平时讨论增量，双方各自的定义没被放到台面比较；关键时刻讨论"对不对、算不算、该不该"，定义第一次成为判定依据，裂缝才显形。矛盾出现时的对齐，已经是在收拾残局了。
- **P9 翻译伪朋友 = 历史 + 语言结构**：三个历史原因——翻译逐词对应把本不相关的词译成形近字；1990 年代术语集中涌入、翻译风格不一；中文是意合语言，不能靠词根一眼看出词族关系。
- **P10 概念不对齐的代价延迟结算**：平时看不见，到合同纠纷、验收分歧、需求变更时才一次性结算。对齐的代价是三分钟，不对齐的代价是两个月。
- **P11 九格由三类误解反推**：每种病需要什么信息，就给它一格；四层——定界/溯源/致用/纠误。
- **P12 薄格可省、不可跳过**：跳过的那一格，往往是误解潜伏的地方；填不出"背景"可能根本不知道为什么用它，填不出"误区"可能正处在误区里。
- **P13 九格是动作不是知识**：每一次使用，都是把"我以为"变成"它定义上是什么"。
- **P14 语境决定所指**：一词多概念用哪个看语境；九格不是规定"只能用哪个"，是要求你"说清楚用的哪个"。
- **P15 九格是"该查时查全"的尺子，不是"每次都要量全"的尺子**：日常使用只动其中两三格。
- **P16 概念对齐是后续所有动作的前提**：不对齐的会议，不仅浪费四十分钟，还会把错误的决定付诸执行。

### 重要分界与落点
- 晨星暮星思想实验 → 放大为"几百个词的世界"
- 比喻："术语是名牌，概念是名牌背后的人"（名牌可换、同名可挂不同人）
- 同物异名=漏的根源、同名异物=吵的根源
- 架构漂移史：建筑 → 软件 → 组织 → 数据，一个能指挂五个所指
- 三病合起来 = 词汇病完整画像；治三病靠一把尺子（九格）
- 九格四层（定界→溯源→致用→纠误）+ 反推逻辑
- 约三十张核心档案，分布在后面章节
- 九格三场景：开会前对齐 / 审文档当检查单 / 写规格先填档案；三层：个人 / 团队 / 组织
- 认知链：第1章发尺子 → 第2章起逐章钉概念
- 章末认知反转："你没有错，但你说的话没法验证对错，因为你没有用定义说话"

### 重要度分层
- **必须钉死（一级）**：术语≠概念（能指/所指分家）、涵义≠指称、例子≠定义、三形态、九格尺子、语境决定所指
- **高（二级）**：同物异名/同名异物、漂移机制（始于言语）、病二平时不爆关键时刻爆、薄格可省不可跳过、钉死≠反对演化
- **中（三级）**：翻译伪朋友三个历史原因、九格反推逻辑、约三十张档案分布
- **较低（背景）**：认知链全景、两条案例线、三种读法

### 本章判据（五条）
1. **术语是能指，概念是所指**——同一个词可以指向不同概念，别让词替概念背锅。
2. **误解的三个形态**——说不出定义（病一）、同词异义（病二）、翻译伪朋友（病三）；认清病，才知道用什么药。
3. **九格尺子钉死概念**——定界（定义/对立/辨析/英文）·溯源（背景/历史）·致用（问题/场景）·纠误（误区）；薄格可省，不可跳过。
4. **用定义说话，不用例子说话**——例子是插图，不是定义；定义带可检验判据。
5. **九格是动作不是知识**——开会前对齐、审文档当检查单、写规格先填档案。

## 第 2 步 · 量学立标

### A. 概念层（12 条）

| # | 概念 | 一句话 | 掌握标准 | 档 |
|---|---|---|---|---|

| 5 | 同物异名 | 同一指称、多个涵义 | 给无害（别名）/有害（重复建设）各一例；说出它是漏的根源 | 能解释 |

### B. 原理层（16 条）

| # | 原理 | 机制 | 掌握标准 |
|---|---|---|---|
| P1 | 语言是约定 | 不是精确编码；模糊是 feature | 解释"模糊是 feature 不是 bug"；能反驳"语言该像编程语言一样精确" |
| P2 | 能指任意、所指实质 | 社会约定决定能指 | 解释"苹果叫 banana 你想到的还是苹果"；任意 ≠ 随意 |
| P3 | 涵义 ≠ 指称 | 同一指称可多涵义 | 用晨星暮星说清；区分"概念"和"事物本身" |
| P4 | 漂移始于言语 | 语言规则慢慢变，先变在某个人的某次言语 | 说清"每个不精确使用都在为漂移添砖"；漂移要众人跟随才成 |
| P5 | 漂移无害、不对齐才可怕 | 钉死 ≠ 反对演化 | 说出"反对的是同会三版本演化"；区分钉死与阻碍灵活 |
| P6 | 同物异名=漏、同名异物=吵 | 两游戏各一害 | 用"合并重复建设"与"四十分钟吵架"各配一例 |
| P7 | 例子 ≠ 定义 | 定义答"是什么"、例子答"长这样" | 判断一句话是定义还是例子；定义要带可检验判据 |
| P8 | 病二平时不爆、关键时刻爆 | 增量不显形、判定才显形 | 用"两份合同合并条款冲突"类比解释；说出"不能等矛盾出现再对齐" |
| P9 | 翻译伪朋友 = 历史 + 语言结构 | 逐词翻译 + 术语集中涌入 + 中文意合 | 说三个历史原因；用"回英文原词"现形；会查词根/看归组 |
| P10 | 不对齐代价延迟结算 | 平时看不见、关键时一次性结算 | 用医疗器械验收案例复述；说出"对齐三分钟 vs 不对齐两个月" |
| P11 | 九格从误解反推 | 每种病需要什么信息给一格 | 说出病一/二/三分别反推出哪些格；不把九格当拍脑袋 |
| P12 | 薄格可省、不可跳过 | 跳过 = 误解潜伏处 | 用"等级"档案解释薄格；区分"省"与"跳" |
| P13 | 九格是动作不是知识 | 把"我以为"变成"定义上是什么" | 说出三场景三层；在自己工作里选一个动作 |
| P14 | 语境决定所指 | 一词多概念靠语境定 | 对"架构"三种语境分别指出所指；说出"九格要求说清楚用哪个" |
| P15 | 该查时查全 vs 每次量全 | 判定时刻查全、日常用两三格 | 说出什么时候该查全（评审结论/验收标准/需求变更） |
| P16 | 对齐是后续一切前提 | 不对齐会把错误决定付诸执行 | 说出"对齐三分钟 vs 不对齐两个月"；解释为什么是第1章 |

## 第 3 步 · 度人察误

**总根源**：人信"看得见的近端"——背得下词、举得出例、数得清次数；概念的判据全在"看不见的远端"（所指、边界、机制、语境）。四机制：
- **①载体误判**（用什么做 = 是不是）：背词 = 懂、举例 = 懂、名词 = 定义
- **②结果误判**（做成了 = 做得好）：没爆 = 没病、测试全过 = 验证过、功能上线 = 验收过
- **③范围误判**（看得见的局部 = 全部）：词 = 概念、译名 = 原词、例子 = 定义、薄格 = 不重要
- **④定义缺席**（词汇病：用头衔/名词/例子代替定义）

### 概念层误解（14 条，★=高杠杆）

| 概念 | 学员常识（原话） | 误解点 | 机制 | 反转 |
|---|---|---|---|---|
| 术语/概念 | "术语和概念是一回事" | 词当概念 | ④★ | 术语是能指（名牌），概念是所指（人） |
| | "名词能替我定义" | 名词当定义 | ④ | 名词是标签，标签背后的人才需要定义 |
| | "同一个词各指各的 = 人不对付" | 人当根因 | ③★ | 不是人不对付，是词对不齐 |
| 能指/所指 | "'苹果'两个字就是苹果" | 符号当实物 | ③ | 能指是形式、所指是内容，二者靠约定相连 |
| | "能指任意 = 我可以随便用词" | 任意当随意 | ②★ | 任意是相对所指的约定，不是随意；约定是社会性的 |
| 语言/言语 | "语言该像编程语言一样精确" | 约定当编码 | ③ | 语言是约定，模糊是 feature；灵活的另一面是歧义 |
| | "我怎么用词无所谓，规则不会变" | 言语当与语言无关 | ③★ | 漂移始于某个人的某一次言语；每个不精确使用都添砖 |
| 涵义/指称 | "晨星暮星是两颗星" | 涵义当指称 | ②·④ | 同指称异涵义，都是金星 |
| | "一个词背后就一个东西" | 两概念混淆 | ④ | 涵义 ≠ 指称是弗雷格核心贡献 |
| 两种游戏 | "同物异名就是别名，小事" | 漏的风险看不见 | ③★ | 有害版 = 以为谈两件事其实谈同一件 = 重复建设 |
| | "同一词各指各的 = 文字游戏" | 吵的根源看不见 | ④·③ | 四十分钟吵架就是同名异物 |
| 术语漂移 | "钉死定义 = 刻板 = 阻碍灵活" | 钉死当反对演化 | ④★ | 钉死反对同会三版本，不是反对演化 |
| | "术语漂移是坏事，有人乱用词" | 漂移当错误 | ③ | 漂移是语言自然演化；有害的是没人察觉漂移 |
| 病一 | "'评审就是开会'是评审的定义" | 例子当定义 | ④★ | 例子是插图不是定义；定义带判据 |
| | "说得出例子 = 懂定义" | 举例当理解 | ②★ | 懂 ≠ 能定义；没判据的理解关键时刻是事故种子 |
| 病二 | "平时没出过词不齐 = 没这病" | 没爆当没病 | ③★ | 平时增量不显形；判定时刻定义才成依据 |
| 病三 | "验证和确认差不多，都是证明没问题" | 译名近亲当同义 | ④★ | 翻译伪朋友；验证对需求、确认对用途 |
| | "中文术语是权威，不用看英文" | 译词当原词 | ③ | 中文模糊处，回英文原词现形 |
| 九格 | "九格每格都必须填满" | 表格当仪式 | ③ | 薄格可省；该空时空着是对概念诚实 |
| | "九格太繁琐，每次开会都填" | 完整性清单当日常仪式 | ③★ | 该查时查全，不是每次量全 |
| | "字典定义不就行了吗" | 定义当全部 | ③ | 定义治不了三病；多出的八格全是误解藏身处 |
| 概念档案 | "薄格 = 没填 = 不重要" | 薄当不重要 | ③ | 薄格可省不可跳过；跳过那格往往是误解潜伏处 |
| | "九格是知识，学会就行" | 尺子当知识 | ③ | 九格是动作不是知识 |

### 原理层误解（8 条）

| 原理 | 学员常识 | 误解点 | 机制 | 反转 |
|---|---|---|---|---|
| P1 | "语言模糊是缺点，应改造成精确编码" | feature 当 bug | ③ | 模糊是 feature；能灵活表达才被几亿人共用 |
| P2 | "能指任意 = 我可以随便发明词" | 任意当随意 | ④②★ | 任意是相对所指的约定；约定是社会性的，随便发明没人懂 |
| P4 | "术语漂移是词典编辑者的事，与我无关" | 演化当外部事件 | ③★ | 每次漂移始于某个人的某一次言语——就是我们 |
| P5 | "钉死定义 = 阻碍语言演化" | 对齐当反对演化 | ④① | 钉死反对的是同会三版本，不是演化 |
| P7 | "例子就是定义，说得出就是懂" | 插图当定义 | ④★ | 例子只答"长这样"，定义才答"是什么"+判据 |
| P8 | "没爆过 = 没病；等爆了再对齐" | 结果当判据 | ③★ | 矛盾出现时的对齐已是收拾残局 |
| P9 | "验证确认评审都差不多" | 译名当词族 | ④★ | 英文现形；review/verification/validation 三个词 |
| P10 | "对齐是开会前的小动作，可做可不做" | 动作当可选项 | ③ | 不对齐代价一次性结算；三分钟 vs 两个月 |
| P14 | "一个词多概念 = 这词有问题/说不清" | 词当责任 | ③④ | 语境决定所指；要求说清楚用哪个，不是消灭多义 |

**门禁**：每条误解是"学员信了相反的东西"（不是知识盲区），且是学员真实会信的常识（不是纸面稻草人）。

## 第 5 步 · 正误有方

### 强化点优先级（按消除误解的杠杆排序；★1 最重）

| 优先 | 强化点 | 反制哪些误解 | 练到何种程度 |
|---|---|---|---|
| ★1 | 术语 ≠ 概念（能指/所指分家） | T1/T6/T10/T15（定义缺席 + 载体误判的总根） | 脱口：听到"架构"自动问"哪个所指"；说得出"名牌 ≠ 人" |
| ★2 | 例子 ≠ 定义，定义带判据 | T4/T5/T12（病一 + 结果误判） | 肌肉记忆：听到"X 就是……"先问"定义还是例子？判据呢？" |
| ★3 | 漂移始于言语 + 钉死≠反对演化 + 任意≠随意 | T8/T9/T11/T15（一条机制串多个陷阱） | 能解释"每个不精确使用都为漂移添砖"；能区分钉死与阻碍灵活 |
| ★4 | 病二平时不爆、关键时刻爆 | T7（没爆 = 没病） | 能解释"增量不显形、判定才显形"；不等爆了才对齐 |
| ★5 | 翻译伪朋友三动作 | T5/T16（伪朋友 + 中文权威） | 能手写 review/verification/validation 三词对照 + 三动作 |
| ★6 | 九格"该查时查全" + 是动作不是知识 | T13/T14/T15 | 三场景各选一个动作落地（开会前对齐/审文档检查单/写规格先填档案） |

### 纠错红线（十条）
1. **先表态、后翻案**——先让学员把"术语 = 概念""评审就是开会"说出来，翻案才疼（误解是"信了相反"，不是不知道）。
2. **反转精确，别反转过头**——"例子≠定义"≠"例子没用"（例子是插图，认识概念有用）；"钉死≠反对演化"≠"反对钉死"（该钉还是钉）；"语言模糊是 feature"≠"不用对齐"（歧义是要治的）。
3. **判据配机制**——会背"术语是能指"≠会用；每条判据配"为什么"（约定→漂移→不对齐代价）。
4. **归责落到可对照动作，不指责用词人**——"你错了"→"你这句话里'架构'指哪个所指？"；词对齐是流程问题不是人品问题。
5. **教机制不教断言**——防换载体再踩（纠正"评审=开会"后，遇到"验证=测试"还会踩）。
6. **先立尺子再翻案**——九格尺子立起来再翻案，否则学员无尺可依（本章就是发尺子）。
7. **拉开强度层次**——全标 ★★★ = 无 ★★★，留 3~4 个最重靶子下重手（术语≠概念、例子≠定义、病二没爆≠没病、验证确认伪朋友）。
8. **每个纠正落到可操作动作**——讲完"术语≠概念"给"开会前摆词三问"；讲完病三给"回英文原词三动作"。
9. **单一权威**——判据权威在书 + ISO 9000 / 索绪尔 / 弗雷格，不另立标准。
10. **网搜当弹药不当铁证**——事实（ISO 术语组 / 学术研究）进讲师版佐证，观点（博客评论）不当作判据依据。

## 第 6 步 · 化尺为用

### ① 作业指南（优先）——回部门做一次"词汇体检"（照着做）

- **第 1 步 · 收集（30 分钟）**：列出最近一次会议/文档里 5 个最核心的词（质量/需求/评审/验收/架构……）。
- **第 2 步 · 摆词（每人 3 分钟）**：每个词，各写一句"我指的是什么"——不许用例子（判据4）。
- **第 3 步 · 对齐（判据1）**：同一个词，大家的所指一样吗？不一样就各自标出指哪个概念（"架构 = 组织架构/产品形态/系统架构"示范）。
- **第 4 步 · 查病（判据4）**：谁的"定义"其实只是例子？给每个词补一句带可检验判据的定义（"验收 = 功能测试全过"还是"临床用得顺"，判据是什么）。
- **第 5 步 · 验伪朋友（病三三动作）**：涉及英文原词的，回英文、查词根、看归组（验证/确认回 verification/validation）。
- **第 6 步 · 产出**：一张 5 词的"术语口径"一页纸（词 | 所指 | 一句话定义 | 判据 | 英文原词），下次会议开场三分钟过一遍。
- **卡住怎么判断**：写不出判据的词 = 病一（只有例子）；两个所指对不上的词 = 病二（先摆词再谈）；中文译名让人以为是近亲 = 病三（回英文）。

### ② 随身三问（贴墙版）
1. 哪个所指？——这个词现在指哪个概念？（一句话）
2. 定义还是例子？——刚才那句是"它是什么"还是"它长这样"？定义带判据吗？
3. 我钉了吗？——这个会上用到的核心词，大家说清楚用哪个所指了吗？

### ③ 工作检查单（分场景触发；每个"否"触发可讨论发现）

**场景 A · 开会前（3 分钟术语对齐）**
- [ ] 今天会用到的核心词，我列出最容易歧义的 3 个了吗？
- [ ] 每个词，我能用一句话定义（不是例子）吗？
- [ ] 我知道自己说的"架构/质量/需求"指哪个所指吗？
- ⚠ 失败信号：开场 3 分钟没人提"口径"；会议主题里有两个词可能各指各的

**场景 B · 审文档时（九格当检查单）**
- [ ] 文档里每个核心概念，定义给了吗？判据有吗？
- [ ] 哪个概念只有例子没有定义？（病一）
- [ ] 哪个概念和文档里另一个词是近亲却没辨析？（病一/病二）
- [ ] 哪个中文词需要回英文核对？（病三）
- ⚠ 失败信号：读完全文说不出某个核心词的边界；两个词在文档里混用

**场景 C · 写规格时（先填档案再写正文）**
- [ ] 动笔前，核心概念各填一张九格档案了吗？
- [ ] 定义带判据吗？误区格避开了吗？
- [ ] 哪个概念我填不出"背景"（②）？——填不出 = 可能不知道为什么用它
- ⚠ 失败信号：边写边纠结"这个词到底什么意思"

**场景 D · 关键决策时（判定时刻）**
- [ ] 这个决定依赖的词，双方所指一致吗？
- [ ] "验收""完成""通过"这些词，有写在文档里的可检验定义吗？
- [ ] 有没有用同一个词糊住两个概念的缝？（如"验收" = 验证 + 确认）
- ⚠ 失败信号：决策理由里出现"大家都懂""意思差不多"

**场景 E · 术语表维护（组织层活标准）**
- [ ] 术语表不是躺在共享盘的文档——上次谁引用过它？
- [ ] 新人入职、跨团队协作，靠定义还是靠悟性？
- [ ] 术语表本身用九格建档了吗？薄格省了、跳过的不查？
- ⚠ 失败信号：术语表半年没更新、没人引用；新词进团队没人登记

**场景 F · 复盘/分歧时（矛盾出现 ≠ 只能收拾残局）**
- [ ] 这次分歧是"词没对齐"还是"事没谈拢"？——先分清再讨论
- [ ] 我有没有等矛盾爆了才对齐？——平时增量讨论时对齐过吗？
- ⚠ 失败信号：复盘归因"沟通不畅"却没指出哪个词

**使用注意**：分场景触发不一次填满；每个"否"是发现不是追责；反转不过头（例子≠定义≠例子没用、钉死≠反对演化≠反对钉死）。

## 第 7 步 · 淬问成题

### 分组设计（十题两翼）

**第一组 · 概念与原理（5 题）**——概念层能定义辨析、原理层能解释为什么；含**见树见林** 2 题（Q1 概念本身：术语≠概念；Q2 概念关系：七词关系图）。组内循序而进：定义（Q1）→ 关系（Q2）→ 三条机制原理（Q3 语言约定+漂移 / Q4 病二判定时刻 / Q5 九格反推）。

### 题卡全文（10 题 2×5）

**第一组 · 概念与原理（概念层能定义辨析、原理层能解释为什么）**

**Q1（破题 · 见树见林① 概念本身 · 术语≠概念）** 周三上午季度会：老板说"我们公司的**架构**不行，管理层级太多，决策太慢"；产品总监接话"我说的是产品**架构**——M3 的模块边界该重新划了"；技术总监皱眉"你们说的都不是**架构**，系统架构是服务边界、数据所有权这些事"。三个人吵了四十分钟，散会时都觉得"对方不可理喻"。**这场架，到底是"人不对付"，还是"词没对齐"？"术语"和"概念"各是什么？用这两个词解释：三个人为什么都在说"架构"，却从头到尾不在讨论同一件事。** 追问：①三个人的"架构"两个字，是同一个能指还是三个能指？他们吵的是同一个所指，还是三个所指？②"术语是能指，概念是所指"——同一个概念能不能换词？（微服务 = 微服务架构）同一个词能不能指向不同概念？（章首的"架构"）这说明"换不换词"和"换不换所指"，哪个才真正改变讨论？③索绪尔说"能指是任意的，所指才是实质"——为什么名牌可以换、人没变，而同一个名牌挂在不同人身上就要先分清楚？④反身：你刚才给"术语"和"概念"下的定义，是定义还是例子？带判据吗？（懂 ≠ 能定义，当场现形）

**Q2（见树见林② 概念关系 · 符号/能指/所指/术语/概念/涵义/指称）** 天刚亮你指着东方最亮的星说"晨星"，晚上指着西方最亮的星说"暮星"——它们是同一颗星（金星）。有人说："晨星和暮星当然是两颗不同的星，出现的时刻、方位都不一样。"也有人说："同物异名就是个别名而已，小事。"**请给出符号、能指、所指、术语、概念、涵义、指称这七个词的关系——谁包含谁、谁和谁对应。然后用这套关系回答：晨星和暮星是"同一个东西的两个名字"，还是"两个概念"？** 追问：①弗雷格的贡献是"涵义 ≠ 指称"——用晨星暮星说清楚，这个"≠"到底意味着什么？②"同物异名"和"同名异物"两种游戏——为什么一个"是漏的根源"（你以为在谈两件事、其实在谈同一件 → 重复建设），一个"是吵的根源"（你以为在谈同一件事、其实在谈三件 → 四十分钟吵架）？③"同一个概念可以有好几个词"——你身边有吗？（订单 = order、SRS = 需求规格说明书）"同一个词可以指向不同概念"呢？（质量、评审、需求、基线）④反身：你们部门最近一次"对不上"，是漏还是吵？它当时被归因为什么？（自我指涉）

**Q3（原理 · 语言是约定 · 真悖论收束）** 有人说："语言就该像编程语言一样精确——每个词对应一个定义，定义永不变，世界就清晰了。"也有人说："术语漂移是词典编辑者的事，跟我怎么用词没关系。"还有人反驳："把词钉死定义，就是阻碍语言的自然演化，太刻板了。"**语言到底是精确编码系统，还是约定？"术语漂移"始于谁？"钉死定义"反对的，是语言演化，还是别的东西？** 追问：①"语言的模糊是 feature 不是 bug"——这句话在替什么辩护？模糊的另一面是什么（歧义）？如果语言必须足够灵活才能让几亿人共用，那"歧义"是不是它必须付的代价？（**真悖论收束**：语言灵活 vs 概念要对齐——两个都对，靠什么判据分界？→ 同一场会议里三个版本演化，则该当场对齐）②索绪尔说"能指是任意的"——"任意"等于"随便"吗？（语言任意性 ≠ 随意性：我随便发明一个词没人懂，因为能指是社会约定）③"每一次漂移都始于某个人的某一次言语"——"我这次用词不精确"和"语言在演化"是什么关系？我随口一个误用，语言会立刻变吗？什么时候才变？（别人跟着用，用得多了）④反身：你现在的术语里，哪个词正在漂移？你说它的时候，是在为漂移添砖，还是在主动对齐？（自我指涉）

**Q4（原理 · 病二 · 平时不爆关键时刻爆 · 真悖论收束）** 你们的团队平时各干各的，从没为"质量""评审""验收"是什么意思吵过架。有人据此说："我们团队没有词不齐的问题，不用浪费时间对齐。"**"平时没爆"能证明"没有这病"吗？为什么词不齐的问题平时不显形、关键时刻才爆？** 追问：①平时讨论的是"加个功能"这种增量——双方各自的定义为什么不会被放到台面比较？关键时刻讨论的是"这件事对不对、算不算、该不该"——定义第一次成为判定依据，会发生什么？（**真悖论收束**：平时每句话都对齐 = 效率灾难 vs 判定时刻要对齐 = 该较真——两个都对，判据 = 是否进入判定时刻）②"两份合同平时各自执行各自的条款都没问题，一旦合并，条款冲突才暴露"——这个类比在说什么？③"矛盾出现时的对齐，已经是在收拾残局了"——为什么词对齐不能等矛盾出现再做？④反身：你们最近一次"爆了"的分歧，爆之前有没有人先问过"你说的 X 指什么"？如果问了，会怎样？（自我指涉）

**Q5（原理 · 九格从误解反推 · 薄格可省）** 有人说："字典不是给你定义了吗？'架构是系统的组织结构'——为什么还要九格？"也有人说："九格每一格都必须填满，这才是完整理解。"还有人说："九格太繁琐了，每次开会都填九格，谁受得了？"**九格为什么是九格，而不是一格？"每一格必须填满"对吗？九格是"每次都要量全"的尺子，还是"该查的时候查全"的尺子？** 追问：①九格是从哪反推出来的？（病一"说不出定义"→①定义+⑥对立面+⑦辨析；病二"同词异义"→②背景+③历史；病三"翻译伪朋友"→⑨英文来源；乱用→④问题+⑤场景；残余→⑧误区）——"反推"和"拍脑袋"的区别是什么？②"薄格可省，但不可被跳过"——"省"和"跳"有什么区别？"等级"这张档案大部分格子是空的——这是偷懒还是诚实？（该空时空着，是对概念诚实）填不出"背景"（②）可能意味着什么？③"该查时查全"和"每次都要量全"——什么时候该查全？（进入判定时刻：评审结论/验收标准/需求变更）平时为什么不用每次量全？④反身：用你行业里一个词（质量/评审/需求/架构），逐格过一遍，哪一格你最填不出？填不出 = 什么？（自我指涉）

**第二组 · 落地与实践（判据运用 / 场景落地 / 回部门动作）**

**Q6（判据运用 · 病一 · 定义带判据）** 有人问："评审是什么？"答："就是开会过一遍。"再问："一次不走流程的聊天算不算评审？"答："……不算吧。"又问："那怎么判断？"答："不好说，反正评审就是开会。"**"评审就是开会"是定义还是例子？用它能不能判断"一次不走流程的聊天算不算评审"？为什么不能？一个定义要能分得清边界，必须带什么？** 追问：①"定义回答'它是什么'，例子只回答'它长这样'"——"验证就是测试""架构就是画图""质量就是档次高"，每句都少什么？②"说得出口的例子，往往让人误以为自己懂了"——"验证就是测试"这种理解，在什么时候会出事？（评审结论、验收标准、需求变更这些关键时刻）③给"评审"补一个带判据的定义——判据是什么？（得出结论了吗？留下记录了吗？——没有结论、没有记录，按定义它最多算聊天）④反身：你天天用的某个词（需求/质量/上线/通过），你能给它一句带判据的定义吗？还是只能举例？（懂 ≠ 能定义，当场现形）

**Q7（判据运用 · 病二 · 验收 = 验证 + 确认 · 真悖论收束）** 医疗器械公司跟医院签验收条款："系统通过验收后，尾款付清。"谁也没定义"通过验收"是什么。半年后系统上线，医院说"验收没过——临床科室用得顺才算"；公司说"功能测试通过就算"。两边都觉得有理，扯了四个月。最后查合同，"验收"一次都没定义过。**公司以为的"验收"和医院以为的"验收"，各是 ISO 9000 里的哪个词？把"验收"拆成两条之后，纠纷为什么消失了？** 追问：①验证（verification）和确认（validation）的参照各是什么？（对照规定需求 / 对照预期用途）——公司要的是哪个？医院要的是哪个？（**真悖论收束**：医院要确认 vs 公司要验证——两个都对，判据 = 拆成两条各配标准：功能验收对照技术规格 + 临床确认对照实际使用）②合同里一个"验收"，把两种概念的缝用什么糊上了？——中文里还有哪些词在干同样的事？（评审/验证/确认三个译名？）③"概念不对齐的代价，什么时候一次性结算"？（平时看不见，到合同纠纷/验收分歧/需求变更时才结算）④反身：你们最近一份合同/需求/验收标准，定义"通过"了吗？判据是什么？谁写的？（自我指涉）

**Q8（判据运用 · 病三 · 翻译伪朋友三动作）** 有人说："评审、验证、确认差不多，都是证明产品没问题。"也有人说："中文术语就是权威，我们按中文理解就行，不用管英文。"**"评审/验证/确认"是三个相近的词，还是三个不同的概念？怎么用三个动作当场现形？（回英文原词 / 查词根 / 看归组）** 追问：①英文一摆出来：review、verification、validation——三个完全不同的词，中文翻译为什么让人以为它们是近亲？（翻译逐词对应 + 1990 年代术语集中涌入 + 中文意合语言，三个历史原因）②"看归组"——ISO 9000 里评审（3.11.2）和验证/确认（3.8.12 / 3.8.13）各在哪个术语组？"在同一个术语组"意味着什么？（评审和"确定/监视/测量/检验"（3.11 组）是一家；验证/确认和"规范"（3.8 组）是一家——近亲就是该放一起辨析的对象）③为什么中文尤其容易踩翻译伪朋友的坑？（意合语言：不能靠词根一眼看出词族）——概念档案第⑨格"术语英文来源"存在的意义是什么？④反身：你工作中哪个中文词，回到英文才发现是伪朋友？（验证/确认？架构/architecture？治理/governance？）

**Q9（判据运用 · 九格三场景 · 语境决定所指 · 真悖论收束）** 有人说："'架构'在管理语境、产品语境、系统语境是三个概念——中文这么模糊，术语根本说不清，干脆别较真。"也有人说："正因为它有三个概念，我们才要每次说清楚用哪个——较真是应该的。"**中文术语的模糊，是"不说清"的理由，还是"更要说清"的理由？九格在个人、团队、组织三层分别怎么用？** 追问：①"语境决定所指"——"架构"在三种语境各指什么？（组织架构 = 管理层级 / 产品形态 = 模块边界 / 系统架构 = 服务边界）——"九格不是规定只能用哪个，是要求说清楚用的哪个"，这跟"别较真"的区别在哪？（**真悖论收束**：中文模糊 vs 术语要说清——两个都对，判据 = 回到英文原词 + 说清楚所指）②开会前（三分钟术语对齐清单）、审文档（九格当检查单）、写规格（先填档案再写正文）——三个场景各用哪几格？九格为什么"是动作不是知识"？③"该查时查全"和"每次都要量全"——什么时候该查全？（进入判定时刻：评审结论/验收标准/需求变更）平时为什么不用每次量全？④反身：你们部门的下一次关键会议，开场三分钟对齐哪三个词？谁来带头？（自我指涉）

**Q10（落地生根 · 回部门词汇体检）** 章末那句话："你没有错，但你说的话没法验证对错，因为你没有用定义说话。"假设那场带尺子的会议真的重开了：摆词（每人一句"我指的是什么"）→ 对齐（三个所指里只有一个是我们讨论的"架构"）→ 分头处理（组织架构归 HR、产品形态另开评审、系统架构留下专项）——四十分钟的争吵变成十五分钟的对齐加三十五分钟的各干各的。**用同一套流程，给你们部门做一次词汇体检：列出最近一次会议或文档里最核心的三个词，各写一句"我指的是什么"（不许用例子），然后用病一/病二/病三三问检查每个词。然后给出你们部门最应该改进的三个事项——每个事项落到一个可操作动作（一句判据/一个检查项/一条话术）。**（提示：大多数团队会说"我们没这病"——先诚实面对"平时没爆 ≠ 没病"，再谈改进。缺的判据：术语是能指、概念是所指 / 例子不是定义 / 验证确认是伪朋友）

①**直觉能答对的题**——无：每问都打在"信了相反"上（术语=概念 / 晨星暮星=两颗星 / 评审=开会 / 没爆=没病 / 字典就够 / 验证确认差不多 / 中文模糊别较真）；②**无追问链的题**——无：每问追问链至少三层（机制→判据→归责/自我指涉/反身）；③**不看导读就无法下手**——无：概念锚点在导读给足（能指/所指/涵义/指称/九格），题面自足；④**题内容在书里找不到依据**——无：全部来自 §1~4 与案例进展（言必有书）；⑤**点头"本来就知道"**——无：见树见林两题（Q1 定义、Q2 七词关系）专治"以为知道"；⑥**翻案后答不出"那怎么办"**——有落点：Q6③ 定义判据 / Q7 拆两条各配标准 / Q9② 三场景动作 / Q10 三个可操作事项；⑦**只是"不知道"而非"信了相反"**——无：每问断言皆常识、皆错；⑧**卡在"不了解背景"**——无：医疗器械验收案例原因题面给全（题面自足）；⑨**翻案停在"一方错"**——无：Q3（语言灵活 vs 概念对齐）、Q4（平时效率 vs 判定正确）、Q7（医院确认 vs 公司验证）、Q9（中文模糊 vs 术语要说清）已含真悖论收束，Q5 内嵌"该查时查全 vs 每次量全"两面硬币，其余为单断言陷阱或落地题。
