# 封面设计说明

> 本书封面——前封 + 书脊。设计概念：**物种标本卡**。书名问"架构师是个怎样的物种？"，封面就把它当物种来定名：标本卡语法（细双框 / 学名 / 特征 / 朱文印）恰好装下这本书的方法论。
> 源文件：`封面-前封书脊.svg`（可改可出片）；预览：`封面-前封书脊.png`（860×1132）；重渲：`node render-cover.cjs`（NODE_PATH 指向含 puppeteer-core 的 node_modules）。2026-08-23 初稿；2026-08-25 出版社暂定。

---

## 一、版式

- 成品比例 **A5 竖版**：前封 800×1132 + 书脊 60 宽（合 860×1132，≈148×210mm @ 147dpi 预览档；出片另置高分辨率）。
- 前封内部 **细双框**（标本卡/实验记录的克制秩序），内容区左右对齐在 132 / 788（对称于版心 460）。
- 阅读动线：题词 → 书名 → 副题 → 尺子与攀升 → 学名与特征 → 朱印。

## 二、设计概念 → 书的映射

| 封面元素 | 对应书的什么 |
|---|---|
| 顶部题词「大部分人在不准确的地基上盖房子」 | 全书使命（00-全书框架 §一） |
| 书名两行 + 朱红「？」 | 书名即问题；「？」=概念要答全四问才算拥有（第1章四问法） |
| 副题朱红破折 +「从工程师到架构师」 | 副题；破折 = 书里两条案例线的引线 |
| 尺子基线 + 主次刻度 | 判据主义——每个概念配一把可当场检验的尺子 |
| 三粒度攀升线（工程师→系统工程师→架构师） | 第9章三角色粒度谱系；升线即「从工程师到架构师」 |
| 学名 Architectus Systematis | 九格⑨术语英文来源；物种学名（本书虚构，非正式分类） |
| 特征「兼具架构活动能力和职责的工程师」 | 架构师=兼具架构活动能力和职责的工程师（工程师底座 + 架构活动能力 + 结构演化专责；「兼具」强调能力与职责双在）；架构活动=architecting 既定译法，依据短语「贯穿系统生命周期的、对架构进行构思、定义、表达、记录、沟通、认证恰当实现、维护与改进的过程」（依据 ISO/IEC/IEEE 42010 §3.1 architecting 定义词条；42020 架构过程同源，正文以 42010 §3.1 为准——2026-08-25 双源核对） |
| 朱印「把话说准」 | 使命与序言主题；中文书卷气收口 |
| 细双框 | 标本卡/实验记录语法；「给边界、不把话说满」的秩序感 |
