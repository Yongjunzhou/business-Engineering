# 章末件块序改定（2026-09-26 用户定案）

**用户令（两轮）**：
1. 「**把本章概念总图、自查、练习等内容，迁移到小结之后**」；
2. 「（**本章的能力级** 那一块＋收束句）**迁移到自查之前，概念总图之后**」。

## 一、新块序（18 章一律）

```
章末 · 认知反转  →  小结  →  本章概念总图  →  本章的能力级（四层清点块＋"见过→拥有"收束句）
                                              →  本章判据（若有）  →  自查  →  练习  →  参考文献
```

**用意**：反转与小结把这一章的话**说完**；总图与"本章的能力级"是**读者带走的东西**（地图＋刻度＋签名句）；判据／自查／练习是**工具与自查材料**；**参考文献恒在最后**。

**★ 第2轮改动（2026-09-26）**：明线两件回收件（清点块＋收束句）原在「章末 · 认知反转」末尾，现**独立成块**、排在**总图之后、自查之前**——**第1章已落地**；**其余 17 章的刻度行随"四层清点"批次一并按新位置落位**（该批未施工）。体例落点：框架 **§五 第 12 条**（v2.98）。

## 二、旧块序（改前，18 章一致）

```
本章概念总图  →  章末 · 认知反转  →  本章判据  →  自查  →  练习  →  小结  →  参考文献
```

## 三、做法与验收

- **只搬块、未改一字**：脚本 `.work-style/reorder_chapter_tails.py`——按 `##` 切块，先 **dry-run 逐章核对"章末件认得全、无未登记块"**，18 章全认得（唯一差异＝第1章无判据块）→ 落盘。
- **复检** `.work-style/check_tail_order.py`：**18/18 章顺序正确**、围栏全配平；`00-风格参考-量尺.py`（口径 v3，按标题归类，与顺序无关）与 `00-三条线索-核对.py`（**收束句 18/18、刻度行 17/17**）均不受影响；第1章 `check_ch1.py` 全过。
- **体例落点**：`00-全书框架.md` **v2.96**——§五 头部加"★ 章末件块序"一行、第 6 条改为「**章末附件块（含块序）**」、第 4 条补明线两件回收件（收束句＋四层清点块）。

## 四、注意

1. **章末三块的分工未变**：反转＝收口｜小结＝说完整章｜总图＝一页地图｜判据／自查／练习＝工具与自查材料；
2. 第1章**无判据块**（同日另一定案，见 `本章判据块退出第1章.md`），其块序为"反转 → 小结 → 总图 → 自查 → 练习 → 参考文献"；
3. 成书构建按文件顺序输出，故**这份块序即读者的阅读顺序**——今后新增章末件，一律插在"练习"之前、"小结"之后。
