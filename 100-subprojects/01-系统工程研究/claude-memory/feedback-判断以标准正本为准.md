# 判断以标准正本为准，研究报告只作取料

## 裁定原文与场景

2026-10-13 本轮讨论（架构视图／物理视图／分解结构／设计空间）中，用户两次纠正：

> **"你应该看标准，而非看研究报告。"**

起因：我先把 **34 号研究报告**的对照表与 **INCOSE SEH（手册，二手）** 的措辞当承重依据递上去；用户要求全部回到标准正本。

## 规则（照此办）

1. **判据只取标准正本**：`ISO_IEC_IEEE 42010 2023-中英文对照版.md`（正文为 42010:2022）／`ISO-IEC-IEEE 42020 2019-中英文对照版.md`／`ISO IEC IEEE 42030-2020-中英文对照版.md`／`ISO IEC IEEE 15288 2023-中英文对照版.md`。
2. **研究报告（00~36 号）与手册（SEH）不等于判据**：可作取料、索引与提示，**凡结论入正文或答复，须回标准条款重核并标注条款号**。
3. **凡标"标准里没有"的，先做零命中检索再断言**（本轮：`physical object`／`product breakdown structure`／`functional architecture` 在 42010:2022 中零命中，均已实测）。
4. **引用要标层级**：标准原文逐字／标准可支持的读法／按定义句作的举例／我自己的定性——四档分清，不许混写。

## 当轮自纠三处（留痕，可复查）

|---|---|---|
| 1 | "分解结构族＝WBS／FBS／PBS／OBS／CBS" | 五项清单是 **SEH** 的；**15288:2023 §6.3.1 NOTE 4** 的四项清单是 WBS、功能分解结构、**系统分解结构（SBS）**、OBS |
| 2 | 用 SEH p103"PBS 展开物理架构细节"给 PBS 定位 | SEH 是手册；标准侧只能说到"分解结构属项目规划过程的人工制品"（Table B.1） |
