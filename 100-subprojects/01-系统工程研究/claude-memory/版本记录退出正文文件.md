# 版本记录退出正文文件（2026-09-26 用户定案）

**用户令**：「**把版本记录给去掉**」。

## 定案内容

- **书的正文文件不再附版本表**——范围＝序言／前言／第1~18章／后记／附录（**共 22 个文件**，第1章随 v3.0 先去掉，其余 21 个同批清扫；脚本 `.work-style/strip_version_tables.py`，删前 dry-run 逐个核对"其后无正文"）。
- **版本历史改以 git 提交与 `claude-memory/` 为准**——每轮改动写进提交信息与记忆卡，不再往正文文件里追加行。
- **元文件仍保留版本表**：`00-全书框架.md`／`00-方法论的底座.md`／`00-三条线索.md`／`00-案例设定.md`／`00-风格参考.md`／`00-对话范本.md`／`00-目录.md`／`00-工作二审计清单.md`——它们是**体例与判据的审计痕迹，不入书**。
- **成书不受影响**：`成书/build/preprocess.mjs` 本就有 `stripVersionRecord()`，构建时逐文件剥掉此节。

## 影响与注意

1. **章内的"版本 +1"习惯随之作废**——以后改章，只在提交信息与记忆里记版本号；
2. **审计链改道**：查"某处何时改的"须回 git（`git log -p -- <file>`），文件内不再有痕；
3. 若日后要恢复正文版本表，可 `git revert` 本次清扫提交，或在构建侧保留（构建本来就能剥）。
