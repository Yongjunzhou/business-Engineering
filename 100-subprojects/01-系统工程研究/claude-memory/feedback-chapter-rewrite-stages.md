# 每章重写分四个阶段（2026-09-26 定三阶段；2026-09-27 增设第一个阶段，同日再增「主线」并把读解基础扩为五类）

**用户原话（2026-09-27）**：「**修订手册中给出的修订过程是三个阶段，我希望增加一个阶段，而且是第一个，给出你认为本章的目的、目标、内容概要，我确认后再进入第二阶段**」；同日续定：「**给出本章的目的、目标、主线、内容概要，其中主线要支撑本章题目**」→「**第一个阶段中，增加：深入理解本书的目的、目标、主线（三条线），本章之前各章的目的、目标、主线、概要和框架以及它们对本书目的、目标和主线的支撑**」。

| 阶段 | 产出 | 过的关 |
|---|---|---|
| **一、本章的目的、目标、主线、内容概要** | **为什么写**（目的）／**写出来要达成什么**（目标）／**由哪一句话串起来**（主线，**★ 必须支撑本章题目**）／**打算写哪些内容**（内容概要）——**在取料之前先把"这一章要干什么"立住**。**★ 读解基础＝五类（2026-09-27 用户定，读完再立）**：**① 本书的目的、目标、主线（三条线）**（深入理解；说出三条线各在第几章立·怎么逐章回收，并指出本章站在主线的哪一站）→ **② 书目录顶层全部 00 号文档**（**17 md＋2 py**，通读取规矩）→ **③ 报告库所有研究报告与标准**（编号 00~34 含 7 份对话记录／库内标准正本／非编号件／`90-治理登记`，逐份过、每份给判定）→ **④ 本章之前各章的目的、目标、主线、概要与框架及其对全书目的·目标·主线的支撑**（逐章答三句＋两句：它为什么写／它交了哪一句／它撑住了全书主线哪一段 ＋ 它讲到哪里为止·本章不得重复什么）→ **⑤ 本章现行内容**（**通读但只作参考**，看清缺口与承接，不用它定目的）。**★ ①④ 的读解底本＝[`00-主线与各章支撑.md`](../03-架构师是个怎样的物种/00-主线与各章支撑.md)**（§一 全书；§二／§三 各章卡片） | **★ 展示（贴全文）**→ 对话确认 → 进阶段二 |
| **二、原料清单** | 本章重写要用的全部原料（版本·位置·用法）；取料＝四步（先读顶层全部 00 号文档 → 再逐份过报告库全库并每份给判定 → 后出清单；**现行内容仅作参考、不参与定清单**） | **★ 展示（贴全表）**→ 确认 → 进阶段三 |
| **三、本章框架** | 七件＝主张＋结构＋内容重做清单＋案例与对话＋比喻处置＋连带清单＋待裁事项（**每一项都要写清与本章主线的关系**） | **★ 展示（贴全文或逐条对照表）**→ 逐条确认 → 进阶段四 |
| **四、本章内容** | 按确认的框架写出正文（含章末件与全部连带） | **★ 展示（可读成稿＋改动与复算）**→ 确认 → **提交＋双推** |

**五条纪律**：① **阶段一不过，不取料**（不知道要写什么，就不知道要什么料）；② 阶段二不过，不设计框架；③ 阶段三不写正文；④ 阶段四确认之后才提交＋双推；⑤ 每一阶段的产出都要**先展示、后确认**——只给摘要、只给路径、或把一句"同意"当成对没展示过的东西的确认，都不算过关。

**六条口径**（阶段一）：① 现行内容只作参考；② 概要到"讲哪几件事"为止；③ 过关判据＝后三阶段能拿它当尺子；④ **本章主线要支撑本章题目**；⑤ **本章要接得上全书与前序各章**（当场答"接的是前序哪一章交下来的哪一句"与"撑的是全书主线的哪一段"）；⑥ **★★ 权重：只有"本章之前的各章"作权威**——**本章与后续各章的内容不作权威、参考权重 <10%**（用户 2026-09-27 定：「本章及后续在修订时大概率会被修订，因此本章及后续章节的内容不做为权威」）；用法＝前序各章当判据用，本章现行内容只看缺口与承接，**后续各章只看"全书大致走到哪、别把后面该讲的话讲掉"，不作论据**。

**一句话记法**：**先懂全书（目的·目标·主线三条线）与前序各章 → 目的·目标·主线·概要 → 原料清单 → 框架 → 内容，一阶段一确认；每一阶段先展示、后确认；未经确认，不进下一阶段、更不落库。**
