## 二、八步详解

### 第 1 步 · 剖章立骨（核心概念×原理）

- **输入**：教材书一章——章首误解现场 / 本章问题 / 正文概念档案 / 反直觉命题 / 判据 / 自查练习 / 案例进展 / 章末反转
- **动作**：先立骨架再进细节——先读 `00-全书框架.md` §三 该章行 + 本章**开篇枢纽** + **概念总图**画出章节骨架，再通读全章，**先抓六样**——
  1. **核心概念**：本章要钉死哪几个概念（一句话定义，即概念档案的主概念）；**顺带标注哪几个是根概念（承重柱）**——先抓根、再展骨架（第1章 §1.2.4），承重柱是第 2 步"必须脱口"档的首选；
  2. **对立概念**：每个核心概念站在谁的对立面（远界，如 工程 × 手艺 / 科学 / 艺术）；
  3. **关联概念**：每个核心概念和谁有相关关系、和谁最像但不一样（近界 / 辨析，如 评审 × 验证 × 确认）；
  4. **核心原理**：这些概念成立的机制（为什么，含反直觉命题的底层机制）；
  5. **对立误解**：每个原理对应的"学员最常信的反面常识"（喂给第 3 步误解库 / 第 4 步陷阱清单）；
  6. **四问萃取**：每个核心概念从概念卡（已四问化）过一遍四问——是什么 / 不是什么 / **从哪来（②背景·③演化，溯源）** / **往哪去（④拟解决问题·⑤适应场景/失效边界，致用）**；溯源与致用是显式萃取目标（第1章 §1.7.2"能答全四问才算拥有"）——薄格标注"可省"，**不得默认跳过**（九格 §1.7.5"跳过的格往往是误解潜伏的地方"）。
  以「概念 × 原理」为骨架，再挂判据、案例进展、自查练习；按「概念 / 原理 / 判据 / 案例」分层，标书节号、辨主次。（章首误解现场 ↔ 章末认知反转的首尾呼应作为通读线索，用来印证骨架，不作第一关注）
  **块↔题组对齐（省一步推导）**：正文第一块「是什么」→ 第一组·概念题（见树见林）；第二块「不是什么」→ 真悖论 / 辨边界题；第三块「怎么用」（第15~18章三幕体例作「往哪去（运用）」）→ 第二组·落地 / 方法时刻题（规则 15）；**两种体例都只有 是什么/不是什么/怎么用 三块——没有"从哪来"这一块，概念卡溯源格（②③）由第 6 样"四问萃取"兜住**。
- **输出**：核心内容地图（**核心概念〔含根概念标注〕/ 对立·关联概念 / 核心原理 / 对立误解 / 四问萃取〔溯源·致用〕** + 重要分界 / 落点 + 重要度分层 + 本章判据）
- **门禁**：能一句话说出"本章回答什么问题"；**能报出：核心概念（哪几个是根）、每个概念的对立与关联、核心原理、每个原理对立的误解、每个核心概念的溯源与致用（薄格注明"可省"）**。

### 第 2 步 · 量学立标（提炼掌握清单）

- **输入**：核心内容地图
- **动作**：把书内容逐条转成"学员应能……"的能力句——概念（**能答全四问：定义 / 辨析 / 溯源 / 致用**——后两问至少能说清"从哪来（来源动机）"与"往哪去（应用与失效边界）"，第1章 §1.7.2"能答全四问才算拥有，只能答第一问只是见过"）、原理（能解释为什么）、判据（会用）；每条 = 一句话定义 + 掌握标准；掌握标准分三档（必须脱口 / 能解释 / 知道即可），避免全量强掌握；**档位先抓根——本章根概念（承重柱）与最狠判据入"必须脱口"，溯源/致用维度至少入"能解释"**。
- **输出**：三层掌握清单（概念 / 原理 / 判据）
- **门禁**：每条都是**可检验的能力句**，不是知识点复述。

### 第 3 步 · 度人察误（反推学员常识与误解）

- **输入**：掌握清单
- **动作**：站在学员立场，对每条反推"他脑子里已有什么"——信什么、为什么信；按四机制归类：**载体误判**（用"用什么做"判"是不是"）、**结果误判**（用"做成了"判"做得好"）、**范围误判**（把"看得见的局部"当"全部"）、**定义缺席**（词汇病：用头衔/名词代替定义）；机制可**复合标注**（主 + 次，如"事故=技术不够"=结果(主)+范围(次)）。
  误解来源**四源对账（防漏）**：① 第二幕磨边弧（每道"不是 X"是一条现成误解）② 概念卡⑧误区格 ③ 附录 C 误解清单该章行 ④ `00-案例设定.md` §三 该章任务卡的误解现场触发点——四条对账，缺一补一。
- **输出**：常识误解库（常识原话 → 误解 → 机制 → 反转）
- **门禁**：每条误解是"学员信了相反的东西"，不是知识盲区；是学员真实会相信的，不是纸面稻草人。

### 第 4 步 · 辑误成饵（构陷阱清单，含网搜验证）

- **输入**：误解库
- **动作**：把误解写成「病（断言原话）→ 药（反转）→ 判据（可操作标准）」三栏靶子；按强度三因子粗估排序（**普遍性 × 自信度 × 反转深度**）标 ★★★ / ★★ / ★；用网搜验证陷阱存在、补新陷阱——**网搜当弹药、不当铁证**，区分事实（调查报告）与观点（博客评论）；**超出书处的机制标注"超出书处"由作者裁决**，防书外内容悄悄进题卡。
- **输出**：陷阱靶子清单（病 → 药 → 判据）+ 网搜印证表
- **门禁**：靶子是"大家都信、从没怀疑"的常识（越像明摆着越值翻）；能标出**空白靶子**（现题未覆盖）；"没人写文章反驳"本身是"最普遍"的证据。

### 第 5 步 · 正误有方（定纠错策略）

- **输入**：陷阱清单
- **动作**：定高杠杆强化点（一个知识点反制多个误解的 → 练到"脱口而出"，标"练到何种程度"）；列十条纠错红线：先表态后翻案 / 反转精确不造新误解 / 判据配机制 / 归责到可对照动作 / 教机制不教断言 / 先立尺子再翻案 / 拉开强度层次 / 每个纠正落到可操作动作 / 单一权威不另立标准 / 网搜当佐证。
- **输出**：强化点优先级 + 纠错红线清单
- **门禁**：每个强化点有"练到何种程度"；每条红线防一个具体翻车。

### 第 6 步 · 化尺为用（产落地工具）

- **输入**：判据 + 原理（含回部门落地场景）
- **动作**：把判据（尺）操作化为落地工具（随身三问 / 分场景检查单 A~F / 判据速查卡 / 每周一检），**再优先整合成作业指南**——把"回部门落地"做成学员能照着做的多步指南（先做什么、用哪条判据、产出什么、卡住怎么判断）；**作业指南是主产出，工作检查单是它的配套素材**。
- **输出**：**作业指南（优先，回部门落地用）** + 工作检查单（配套）
- **门禁**：**作业指南落到"照着能做"的动作（步骤+判据+话术）**；检查单每个"否"触发可讨论发现；分场景触发，不追求一次填满；**只有纯勾选项的落地才可不产指南（不为产而产）。**

### 第 7 步 · 淬问成题（合成讨论问题清单）

- **输入**：陷阱清单 + 掌握清单 + 作业指南/工作检查单
- **动作**：按**附录 · 题卡设计规则 15 条**合成题卡（**每单元至少一题规则 15「方法时刻」题**——让学员亲手做一遍本章方法底座时刻；跨域/判词变体按章启用）——**十题两翼**定数量与分组：第一组偏概念与原理（须含**见树见林**：概念本身 + 关系 ＋原理陷阱），第二组偏落地与实践（须含**落地生根**：回部门/现状 ＋判据运用）；主问句用**直问其要**（是什么/什么关系/为什么/你/你们，反常识点在问句本身），翻案后接追问链（机制/判据/归责/自我指涉/反身），追问落在强化点 + 判据上；靶子两端皆成立时可升级为**真悖论收束**（附录 10）；用书自己案例，**不发明平行例子**；Q1 以章首误解现场破题。
- **输出**：题卡（10 题）
- **门禁**：覆盖校验**六列全查**（判据 / 概念 / 原理 / 案例 / **方法** / **四问〔溯源·致用〕**，按两组分别查）+ 设题九检——**每个核心概念的非薄格（尤其溯源/致用）在 10 题里至少被覆盖一次；薄格须是有意标注"可省"的，不得默认跳过**（九格 §1.7.5）。

### 第 8 步 · 六件齐备（逐格同步）

- **输入**：题卡
- **动作**：按逐格映射，把题卡摊进六件套——导读（概念锚点 / 要反转的直觉）↔ 讲师版（三栏 / 反转话术 / 纠错红线）↔ 知识卡片（金句）↔ 课后作业（落地）↔ 课后阅读指引（书章 + 附录检索位）；**讲师版与题卡逐问同步扩**：每加一问，三栏 + 反转话术同步扩一栏（防题卡超前讲师版）。
- **输出**：单元六件套 + 作业指南/工作检查单
- **门禁**：覆盖映射表与题卡一致；单一权威（判据引用书和标准，不另立）。

## 三、三条过程要点（前两章跑通后吸收的改进）

1. **顺序**：先做掌握清单 + 误解库，再回头评估现题卡——避免直接逐题磨而漏掉"结构缺口"（如约束、错误可见这类定义/原理层的空白，逐题磨看不见）。
2. **覆盖校验看四层**（判据 / 概念 / 原理 / 案例）——只看判据 + 案例进展会漏掉定义层（约束就是这么漏的）；掌握清单是校验的锚。
3. **"没人反驳"= 最普遍的误解**——靶子优先级 = 常识自信度 × 反转深度；一个误解若没有文献专门痛批它（如"约束是敌人"），往往因为人人都默认它对，这恰恰是它最值得翻的证据。
4. **四问兜住"从哪来"**——现行两种体例都只有 是什么/不是什么/怎么用（第15~18章作"往哪去（运用）"），**没有"从哪来"这一块**；概念卡溯源格（②③）不显式萃取就进不了题卡。每单元每个核心概念的非薄格（尤其溯源/致用）至少进一次题，"能答全四问才算拥有"的判据才落在单元上。

## 四、质量门禁速查（八条"不过就停"）

1. ① 剖章立骨——能一句话说出"本章回答什么问题"；核心概念（含根概念标注）、对立/关联概念、核心原理、对立误解、四问（溯源/致用）抓全
2. ② 量学立标——每条掌握标准是可检验能力句
3. ③ 度人察误——每条误解是"信了相反"而不是"知识盲区"
4. ④ 辑误成饵——靶子是"大家都信、从没怀疑"；能标出空白靶子
5. ⑤ 正误有方——强化点有"练到何种程度"；红线防具体翻车
6. ⑥ 化尺为用——作业指南落到"照着能做"的动作；检查单每个"否"触发可讨论发现
7. ⑦ 淬问成题——覆盖校验六列全查 + 设题九检
8. ⑧ 六件齐备——映射表与题卡一致 + 单一权威

## 附录 · 题卡设计规则 15 条

> 出题操作规程（2026-08-20 由 [`00-培训教材-总览.md`](00-培训教材-总览.md) §三 内嵌移入本文件作附录；2026-08-22 增规则 15「方法时刻」）。**单一权威长在此处**；总览 §三「题卡」块只保留件套定义与指针。出题时以本附录为准。

1. **直问其要**（**第一原则 · 首要问法**）：**出题的第一步是直接问，不是先堆断言、不是先造场景。** 主问句一律用直接提问——"是什么 / 什么关系 / 为什么 / 你 / 你们"，让学员**当场产出**对核心概念的理解（定义 / 关系结构 / 清单 / 动作），而不是从选项里认出、从铺垫里猜出。**用"你 / 你们"把问句压到学员自己的理解与角色上——问的是"你怎么理解"，不是"书怎么讲"。** 反常识不靠题外断言堆出来，**靠问句本身点到最容易搞错处**（"开发产品就是开发产品数据吗"式）；"断言 → 表态"只是进入方式之一、不是默认套路（翻案见"以谬为饵"）——**能直接问出答案的题，就不必绕断言。每题收笔前问自己一句："这句话是在直接问，还是在绕着问？"**
2. **题题设伏**（总纲）：每道题都必须同时满足「高度专业 + 反常识（陷阱性）」——10 题里没有任何一道是送分或铺垫题：每题都能先踩坑（反常识）、像行家发问（高度专业）、翻得深落得实。**陷阱性的完整定义：让学员的误解在判断或产出时暴露**——既包括"断言 → 表态 → 翻案"，也包括概念关系题"答错即暴露误解"（见"见树见林"）。
3. **言必有书**（首要规则）：每道题直接从书的核心内容"问题化"——反直觉命题、核心概念档案、判据、自查题、章首误解现场、书内常见问题；用书自己的案例（恒信/冰链/晨星暮星/验收翻车/泰坦尼克·挑战者·737 MAX/机场等），**不发明平行例子**；题目举例与书主要内容的距离，就是该砍掉的部分。（落地追问落到学员自己部门不算题面发明例子，见"落地生根"）
4. **行家之问**：问题要像行业老手当面发问、让人不敢轻易敷衍——落在归责 / 机制 / 判据上、不铺场景；读起来是专业的工程讨论，不是课堂提问。（问句形式见"直问其要"）
5. **十题两翼**：两组各 5 题（共 10 题）——**第一组偏概念与原理**（概念层能定义辨析、原理层能解释为什么）；**第二组偏落地与实践**（判据运用 / 场景落地 / 回部门动作）。覆盖校验按两组分别查——第一组查判据 + 定义 + 原理，第二组查判据运用 + 工具落地。
6. **见树见林**：第一组须含两类**核心概念整体理解**题——**① 概念本身**：直接考核心概念"是什么"（定义 / 内部构成 / 本质，如"工程是什么？四要素怎么构成一个整体？"），用错误断言引出保持陷阱性；**② 概念关系**："请给出 X、Y、Z 的关系"，答案=关系结构本身（链式 / 包含 / 层次 / 对立），其陷阱性在"答错即暴露误解"（如把软件工程当系统工程）。每章两类共 1~2 道。
7. **落地生根**：第二组须含结合学员**自己部门 / 现状**的落地题——"结合现状，请给出你们部门最应该改进的三个事项"式，无标准答案、开放讨论、落到可操作动作（判据 / 检查单 / 一个动作），与课后作业"回部门落地"呼应。**题面仍用书案例，落地追问才把判据用到学员自己部门**（不违背"言必有书"）。
8. **循序而进**：组内「概念 → 原理 → 方法」（即「识别 → 机制 → 判据/落地」）递进：概念层（用定义/判据判断）、原理层（书里为什么这么定义）、方法层（判据怎么用、落地动作）。
9. **以谬为饵**：把书的反直觉命题 / 自查题改造成陷阱——**靶子必须选"大家都信、从没怀疑过"的常识，不是知识盲区**（越被当成"这不是明摆着吗"，翻案越值钱）；翻案后接「追问链」（机制 / 判据 / 推演 / 自我指涉 / **反身**）；**反身**=把刚立的判据量到学员自己的答案上——"你刚才给'X'下的定义可检验吗？还是只能举例？""你们最近一次评审有结论有记录吗？"（懂≠能定义，当场现形）；Q1 对齐章首误解现场作破题。
10. **真悖论收束**（以谬为饵的深度升级）：当靶子两端都是"大家都信、且都站得住"的常识时，把它升级为**真悖论**——两个立场各自为真，靠一条判据自己和解（"语言灵活"vs"概念对齐"→判据"同一场会议里三个版本演化则该对齐"；"平时效率"vs"判定正确"→判据"是否进入判定时刻"；"医院要确认"vs"公司要验证"→拆成两条各配标准）。**翻案不是"你是错的"，而是"两个都对，用什么判据分清什么时候该怎样"**；**真悖论收束后必落回一条可操作判据（判据收束）**，防止论成各说各话。误判迹象：两方各执一词、谁也没给出判据——说明还没收束。
11. **反直觉四维**：每道题的打磨目标，四维一致——**意外**（断言打在大家最自信的地方，与通常认识的距离越大越好——"验收过了就是成功""有流程有测试就是在做工程""版本就是基线"，越像常识越要翻）；**深度**（难度不来自绕弯子 / 冷门知识，来自**机制还原**——把"显然如此"追问到"底层机制是什么、缺了哪一层、换个人换个场景还成不成立"，答得出第一层、答不深第二层的才是深题）；**真悖论是深度的最高形态——不是"错与对"的翻案，是"对与对"的判定**（见"真悖论收束"）；**难度**（要答对走完整条追问链——第一层直觉表态、第二层机制还原、第三层归责 / 判据，层层有坑、没有一望即知的正解）；**收获**（翻案后必须落回**可操作**处——一条判据、一个动作、一句归责；讨论完没有"那我该做什么"，题就没讨论透）。
12. **题面自足**：讨论所需的前提必须写进题面——事故原因、案例细节、定义，一律不给学员留"靠传闻 / 行业背景 / 众所周知"的判断空间（三大事故"知其名不知其因"无法讨论；抽象例"不知道要说明什么"无从判断）。题面给全事实，讨论才建立在同一事实上。
13. **题卡纯问**：题卡**只含问题**——可以含概念问题（问"X 是什么"），但**不含概念讲授 / 概念速览**（概念速览曾加入又因"小儿科"移除）；概念理解支持在导读 + 讲师版。
14. **设题九检**（各规则的门禁清单）：①直觉能答对的题 → 重写（反直觉四维·意外）；②无追问链的题 → 加深（以谬为饵）；③不看导读就无法下手的题 → 导读没把概念锚点给够（题卡纯问）；④题目内容在书里找不到依据 → 离题，砍（言必有书）；⑤学员听完点头"本来就知道 / 这还用讨论" → 意外度不足，换靶子（反直觉四维·意外）；⑥翻案后答不出"那怎么办" → 收获度不足，补落到判据 / 动作的追问（反直觉四维·收获）；⑦学员只是"不知道"而非"信了相反的东西" → 那是知识点不是陷阱题，改断言（题题设伏）；⑧学员卡在"不了解背景"而非"想不明白" → 前提没自证，把事实写进题面（题面自足）；⑨翻案停在"一方错"，没到"两个都对靠判据和解" → 可升级为真悖论（真悖论收束）。
15. **方法时刻**（每单元至少一题）：让学员**亲手做一遍**本章演示的第1章方法（方法底座时刻，取 00-案例设定 §三 该章行）——不考"方法名能不能背"，考"方法会不会用"：判据主义 → 自己给概念立可检验判据；反事实检验 → 自己问"去掉它还成立吗"；织关系 → 自己画概念关系图；**转述（压缩测试）→ 三五句话讲给完全外行的人——讲不清说明结构没成型、卡壳处即边界缺口（五环第3环逼输出）**；意义即用法 → 用"它做什么"定义"它是什么"；先立枢纽 / 见过→拥有 → 先给骨架再进细节 / 把"背得出"推到"答得全四问"；勤校准 → 修正自己一个旧枢纽。两个必选变体：**跨域变体**（有强镜照 / 本章方法=概念跨域的章启用）——用镜照段落 / 00-案例设定 §四 跨域对照表出题"这个概念换个世界还成立吗？判据变没变？"（恒信编号 ↔ 冰链数据所有权），测概念能力第三构件"迁移"；**判词变体**（角色章 ch9/16 必启用）——用本章能力清单判万晖/水恒（万晖有头衔缺①④⑥ / 水恒无头衔缺②⑥），再反身判自己团队，把清单从"背诵对象"变成"判人的尺子"。注：方法底座时刻=判据主义的章（ch3/8/12/13），方法时刻题**就是判据运用题，不重复出**；同方法不同章要有区分（ch3 立质量判据 / ch8 立三把尺子 / ch13 立版本·基线判据）。落点：第一组（概念操作类方法）或第二组（判据运用类方法）；覆盖校验补「方法」列（六列全查）。
