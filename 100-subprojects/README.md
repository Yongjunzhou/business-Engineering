# 子项目区

`100-subprojects/` 是 AOS 项目集的子项目区。AOS 整体是一个项目集：主线由元流水线、EOS 流水线、EOS 本体构成，各子项目是同一工程化目标在其他专业领域的展开。

各子项目自包含在自己的目录中：产出文件、独立记忆 `claude-memory/`、子 `CLAUDE.md` 均落在目录内。子项目之间主题上可互相引用、复用方法；操作上互不干扰，处理某个子项目时不改动其他子项目目录。

| 目录 | 名称 | 性质 | 现行内容 |
|------|------|------|----------|
| `00-topic-research/` | 杂项选题 | 杂项，不是子项目 | 未定形选题的暂存与孵化处；需要继续深入时移出独立为 `NN-` 子项目 |
| `01-系统工程研究/` | 系统工程研究 | 产出型 | 研究报告 → 教材书 `03-架构师是个怎样的物种/` ＋ 培训教材 `02-架构工程师培训材料/` |
| `02-AI部署研究/` | AI 部署研究 | 研究型 | 企业私域大模型推理平台选型；选型研究、专用模型训练与机载部署专项、企业 AI 基础设施建设方案建议 |
| `03-健康研究报告/` | 健康研究报告 | 研究型 | 健康主题书稿讲读摘录 |
| `04-现代思维工具研究/` | 现代思维工具研究 | 研究型 | 思维工具研究，现行 `激励相容/` |
| `05-投资工程研究/` | 投资工程研究 | 产出型 | 材料准备期；播客与访谈转写稿、研究稿落 `00-投资工程研究报告/` |

每个子项目的导航、工作风格与记忆协议见其目录内的 `CLAUDE.md`；子项目记忆位于各自的 `claude-memory/`，与主项目记忆 `.claude/memory/` 相互独立。

项目集共同目标、隔离原则、执行路径与提交边界见根目录 [`CLAUDE.md`](../CLAUDE.md) §九。

复验各子项目是否配齐记忆：

```bash
node .tools/check-subprojects.js
```
