## AI读取文档说明

本文件是树形资产文档。AI 读取时应按需读取，不默认读取全部正文。

默认读取顺序：

1. 读取文档元信息与本说明，确认文档用途、状态和读取规则。
2. 读取 `0. 产品视角业务流程树画像`，建立业务域、产品类型、构件类型、分片与节点规模的整体感知。
3. 读取 `1. 业务流程状态与处理队列`，确定本轮目标节点、活动锁、当前待办 ID 与下游选择记录。
4. 读取 `2. 业务流程节点索引 / 分片索引`，定位目标节点正文块、候选同产品节点块与必要追溯关系。
5. 仅读取目标节点正文块、追溯关系指向的 `02-eos-business-role-process.md` 视图，以及本轮需要写回的反馈区或建议区。

扩大读取范围仅在以下情况允许：

- 节点索引缺失或块 ID 无法定位。
- 追溯关系断裂，无法判断文档级任务在两棵树之间的认亲关系。
- 候选节点存在归属冲突、误新建、误引用，或 WBS 归组冲突。
- 需要执行全局一致性检查或批量迁移。
- 人类明确要求通读全文。

禁止事项：

- 不得在常规运行中默认全量读取正文节点块。
- 不得将旧版正文、废弃节点或历史归档作为当前资产参与判断。
- 不得只凭对话上下文推进状态；人类反馈必须先写入节点反馈区、状态队列或转交记录。

## 3. 规则区 / 口径区

### 3.1 节点口径

- 一个节点 = **一个构件开发WBS（包）**，即一批数据依赖闭合的产品数据单元，由一组按数据依赖链排定的业务文档构成。
- 产品类型（②）＝部门级的端到端业务输出；产品构件类型（③）＝科室级的端到端业务输出。
- 节点内的业务文档 = 本节点的 ⑤ 级，与 `02-eos-business-role-process.md` 里的同名文档**同一次序、同一名称**、实体在那边；占位节点没有 `02` 侧的同名文档，是例外。

### 3.2 schema 单源与判据落点

- 节点正文 schema 单源 = [91 规范](../10-pl4eos-subpl-sysdev/10-wfsysdev-4-eos/91-eos-biz-eng-spec.md) §11 + 本文件 §4.1 模板。
- 树形与级语义单源 = [94 号文档](../10-pl4eos-subpl-sysdev/10-wfsysdev-4-eos/94-eos-sys-dev-dbs.md) §2.2。
- 产品数据即资产；R 树与 P 树即资产，不另立资产文件。

### 3.3 关联产品数据

| 产品数据 | 关系 |
